# Discrete Mathematics Exercises

## Logic and Proofs (Problems 1-5)

**1.** Prove: If n² is even, then n is even.
*Hint: Use contrapositive — assume n is odd.*

**2.** Show that √2 is irrational.
*Hint: Proof by contradiction; assume √2 = p/q in lowest terms.*

**3.** Construct a truth table for (P → Q) ∧ (Q → R) → (P → R).

**4.** Prove: For all integers n, if n is divisible by 6, then n is divisible by 3.

**5.** Disprove: "For all integers a, b: if a² = b² then a = b."

## Sets and Relations (Problems 6-9)

**6.** Let A = {1,2,3}, B = {2,3,4}. Find A ∪ B, A ∩ B, A \ B, and A × B.

**7.** Prove De Morgan's Law: (A ∪ B)' = A' ∩ B'.

**8.** Determine if R = {(1,1),(2,2),(3,3),(1,2),(2,1)} on {1,2,3} is an equivalence relation.

**9.** How many subsets does a set with 5 elements have? How many have exactly 3 elements?

## Combinatorics (Problems 10-14)

**10.** How many ways to arrange the letters in "DISCRETE"?

**11.** A committee of 4 is chosen from 10 people. How many different committees?

**12.** How many 5-card poker hands contain exactly 2 aces?

**13.** Prove C(n,k) = C(n-1,k-1) + C(n-1,k) (Pascal's identity).

**14.** How many integers between 1 and 100 are divisible by 3 or 5?

## Graph Theory (Problems 15-19)

**15.** Draw K_4 (complete graph on 4 vertices). How many edges?

**16.** Prove: In any graph, the sum of all vertex degrees equals twice the number of edges.

**17.** A tree has 15 vertices. How many edges does it have?

**18.** Determine if a graph with degrees 3,3,3,3,2,2 can exist.

**19.** Find the chromatic number of a cycle with 5 vertices (C_5).

## Number Theory (Problems 20-22)

**20.** Use the Euclidean algorithm to find gcd(48, 18).

**21.** Find integers x, y such that 48x + 18y = gcd(48,18).

**22.** Compute 7^100 mod 13 using Fermat's Little Theorem.

## Recurrence Relations (Problems 23-25)

**23.** Solve: a_n = 2a_(n-1), a_0 = 3. Find a closed form.

**24.** Solve: a_n = a_(n-1) + a_(n-2), a_0 = 0, a_1 = 1. Find a_10.

**25.** A tower of Hanoi with n disks requires a_n = 2a_(n-1) + 1 moves, a_1 = 1. Find a closed form.
