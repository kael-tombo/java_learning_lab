# Why It Exists: Logic and Proofs

## The Problem: How Do We Know What Is True?

Before logic, mathematical arguments relied on intuition and informal reasoning. This led to errors: false "proofs" of true statements, true statements with no valid proof, and paradoxes that undermined confidence in mathematics.

Logic exists to provide a **precise, mechanical standard** for determining whether an argument is valid. It separates the *form* of reasoning from its *content*, allowing us to check validity without understanding the subject matter.

## The Foundational Crisis

In the late 19th and early 20th centuries, paradoxes like Russell's paradox (the set of all sets that do not contain themselves) showed that naive reasoning about sets and functions was inconsistent. Mathematicians realized that informal reasoning could not be trusted.

**David Hilbert** proposed a program (1920s): formalize all of mathematics in a consistent, complete, logical system and prove its consistency using finitary methods. Logic was to be the foundation that secured mathematics against contradiction.

## Gödel's Response

**Kurt Gödel** (1931) proved that Hilbert's program is impossible:
- **First incompleteness theorem**: Any consistent formal system capable of expressing arithmetic contains true statements that cannot be proven within the system.
- **Second incompleteness theorem**: Such a system cannot prove its own consistency.

These results show that logic has inherent limits: no single formal system can capture all mathematical truth. But they also clarify what logic *can* do: within a given system, logic provides a rigorous standard of proof.

## The Computational Turn

**Alan Turing** and **Alonzo Church** (1936) showed that the Entscheidungsproblem (decision problem) is unsolvable: there is no algorithm that decides whether an arbitrary first-order formula is valid. This established the boundary between the decidable and the undecidable.

## Why Logic Matters Today

Logic exists because:
1. **Rigorous reasoning**: It provides a standard for proof that is independent of intuition.
2. **Automation**: Logical proofs can be checked by computers, enabling formal verification.
3. **Clarity**: Formalizing arguments exposes hidden assumptions and ambiguities.
4. **Foundation**: Logic underlies set theory, which underlies all of modern mathematics.

Without logic, mathematics would be a collection of plausible arguments rather than a body of certain knowledge.
