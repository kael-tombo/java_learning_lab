# VISION — Logic & Proofs
> From truth tables to induction — reasoning that survives scrutiny.

## Arc
1. **Foundations** — propositions, connectives, quantifiers, ∀/∃ scope.
2. **Fluency** — truth tables, logical equivalences, De Morgan.
3. **Discrimination** — direct vs contradiction vs contrapositive vs induction.
4. **Scale** — formal proof writing: structure, hypotheses, QED.
5. **Production** — specs as pre/post-conditions; invariants in code.

## Milestones
- [ ] M1: truth-table (p∧q)→(p∨r).
- [ ] M2: prove via contrapositive: n² even → n even.
- [ ] M3: induction: 2ⁿ > n for n≥5.
- [ ] M4: negate ∀x∃y P(x,y).
- [ ] M5: write a loop invariant and prove termination.

## Anti-Goals
- Arguing from an example; misplacing quantifier scope.
