# VISION — Set Theory
> Collections, operations, and the algebra of membership.

## Arc
1. **Foundations** — set notation, subset, union/intersection/complement.
2. **Fluency** — Venn diagrams, De Morgan for sets, power set.
3. **Discrimination** — proper vs not-proper subset; empty set vs {∅}.
4. **Scale** — Cartesian product, relations, functions as sets.
5. **Production** — query filters as set operations; dedup as set semantics.

## Milestones
- [ ] M1: power set of {a,b,c}.
- [ ] M2: verify De Morgan on a 3-set Venn.
- [ ] M3: Cartesian product size |A×B|.
- [ ] M4: show a relation is/ isn't a function.
- [ ] M5: express a SQL WHERE as set ops in words.

## Anti-Goals
