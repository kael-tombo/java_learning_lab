# Discrete Mathematics Quiz

## Questions

**Q1.** The contrapositive of "If P then Q" is:
- A) If Q then P  B) If not P then not Q  C) If not Q then not P  D) P and not Q

**Q2.** How many elements are in the power set of {a, b, c}?
- A) 6  B) 8  C) 9  D) 12

**Q3.** C(10,3) equals:
- A) 60  B) 120  C) 720  D) 1000

**Q4.** A tree with n vertices has how many edges?
- A) n  B) n-1  C) n+1  D) n²

**Q5.** Which is NOT a valid proof technique?
- A) Contrapositive  B) Contradiction  C) Counterexample  D) Circular reasoning

**Q6.** In a simple graph, the sum of all degrees equals:
- A) Number of vertices  B) Twice the number of edges  C) Number of edges  D) n(n-1)

**Q7.** If a ≡ b (mod n), then:
- A) a = b  B) n divides (a-b)  C) a/b is integer  D) a and b are prime

**Q8.** The pigeonhole principle states:
- A) Every function is injective  B) n items in m containers with n>m means some container has ≥2  C) All sets are finite  D) Graphs must have cycles

**Q9.** An equivalence relation must be:
- A) Reflexive only  B) Symmetric only  C) Transitive only  D) Reflexive, symmetric, and transitive

**Q10.** The number of permutations of 5 items taken 3 at a time is:
- A) 15  B) 30  C) 60  D) 125

**Q11.** Fermat's Little Theorem: if p is prime and p∤a, then:
- A) a^p ≡ a (mod p)  B) a^(p-1) ≡ 1 (mod p)  C) a^p ≡ 0 (mod p)  D) a^(p+1) ≡ 1 (mod p)

**Q12.** A bipartite graph:
- A) Has no edges  B) Can be colored with 2 colors  C) Is always a tree  D) Has odd cycles

**Q13.** The binomial coefficient C(n,0) + C(n,1) + ... + C(n,n) equals:
- A) n!  B) 2^n  C) n²  D) 2n

**Q14.** The Euclidean algorithm computes:
- A) LCM  B) Prime factorization  C) GCD  D) Modular inverse only

**Q15.** A connected acyclic graph is called a:
- A) Forest  B) Tree  C) Cycle  D) Complete graph

## Answer Key

1. **C** — Contrapositive swaps and negates: ¬Q → ¬P.
2. **B** — Power set has 2^n = 2^3 = 8 elements.
3. **B** — C(10,3) = 10!/(3!7!) = 120.
4. **B** — Trees satisfy |E| = |V| - 1.
5. **D** — Circular reasoning assumes what it proves.
6. **B** — Handshaking lemma: Σdeg = 2|E|.
7. **B** — Congruence means n | (a - b).
8. **B** — Pigeonhole: overflow forces sharing.
9. **D** — All three properties required.
10. **C** — P(5,3) = 5!/2! = 60.
11. **B** — a^(p-1) ≡ 1 (mod p) for prime p.
12. **B** — Bipartite = 2-colorable.
13. **B** — Sum of binomial coefficients = 2^n.
14. **C** — Euclidean algorithm finds GCD.
15. **B** — Connected + acyclic = tree.
