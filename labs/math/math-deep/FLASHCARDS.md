# Advanced Mathematics Flashcards

## Group Theory
| Front | Back |
|-------|------|
| Group | Set with closure, associativity, identity, inverses |
| Abelian group | Commutative group |
| Subgroup | Subset that is itself a group |
| Lagrange's Theorem | |H| divides |G| for finite G |
| Cyclic group | Generated by one element |
| Group homomorphism | φ(ab) = φ(a)φ(b) |
| Isomorphism | Bijective homomorphism |
| Kernel of homomorphism | Elements mapping to identity |
| Normal subgroup | gHg⁻¹ = H for all g |
| Quotient group G/H | Cosets of normal subgroup H |

## Rings and Fields
| Front | Back |
|-------|------|
| Ring | Two operations: (R,+) group, (R,·) monoid, distributive |
| Field | Commutative ring with all non-zero inverses |
| Ideal | Subset absorbing multiplication |
| Quotient ring R/I | Cosets of ideal I |
| ℤ/nℤ | Integers mod n; field iff n prime |
| Polynomial ring R[x] | Polynomials with coefficients in R |
| Characteristic | Smallest n with n·1 = 0 (or 0 if none) |
| Unit | Element with multiplicative inverse |
| Prime ideal | ab ∈ P ⟹ a ∈ P or b ∈ P |
| Maximal ideal | Ideal not contained in any larger proper ideal |

## Metric Spaces
| Front | Back |
|-------|------|
| Metric d | Non-negative, symmetric, triangle inequality |
| Open ball B(x,r) | {y : d(x,y) < r} |
| Open set | Contains a ball around each point |
| Convergence | d(x_n, x) → 0 |
| Cauchy sequence | Terms get arbitrarily close |
| Complete space | Every Cauchy sequence converges |
| Continuous function | ε-δ definition at each point |
| Uniformly continuous | δ depends only on ε, not on point |
| Compact (metric) | Every sequence has convergent subsequence |
| Totally bounded | Covered by finitely many ε-balls |

## Topology
| Front | Back |
|-------|------|
| Topology τ | Collection of open sets (unions, finite intersections) |
| Basis | Collection generating all open sets |
| Closed set | Complement is open |
| Closure | Smallest closed superset |
| Interior | Largest open subset |
| Compact | Every open cover has finite subcover |
| Connected | No separation into two disjoint open sets |
| Homeomorphism | Continuous bijection with continuous inverse |
| Hausdorff | Distinct points have disjoint neighborhoods |
| Dense | Closure equals whole space |

## Analysis
| Front | Back |
|-------|------|
| Monotone convergence | Bounded monotone sequences converge |
| Bolzano-Weierstrass | Bounded sequence has convergent subsequence |
| Uniform convergence | sup|f_n - f| → 0 |
| Radius of convergence | R = 1/limsup|a_n|^(1/n) |
| Lebesgue measure | Extends length to more sets |
| Lebesgue integral | Integrates via measure of level sets |
| Dominated convergence | Pointwise + dominated → integral converges |
| σ-algebra | Closed under complement and countable unions |
| Almost everywhere | Except on a set of measure zero |
