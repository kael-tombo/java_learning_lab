# Advanced Mathematics Exercises

## Group Theory (Problems 1-5)

**1.** Prove that the identity element in a group is unique.

**2.** Show that (ℤ/5ℤ)* (non-zero elements mod 5 under multiplication) is a cyclic group. Find a generator.

**3.** Prove Lagrange's Theorem: For finite group G and subgroup H, |H| divides |G|.

**4.** Determine if S_3 (permutations of 3 elements) is abelian. Justify.

**5.** Find all subgroups of ℤ/12ℤ under addition.

## Rings and Fields (Problems 6-9)

**6.** Prove that ℤ/6ℤ is not a field. Which elements lack inverses?

**7.** Show that the set of 2×2 matrices with real entries forms a ring under matrix addition and multiplication.

**8.** Prove: In a field, the equation ax = b has a unique solution for a ≠ 0.

**9.** Construct addition and multiplication tables for ℤ/3ℤ and verify it is a field.

## Metric Spaces (Problems 10-13)

**10.** Prove that the discrete metric d(x,y) = 0 if x=y, 1 otherwise, satisfies the triangle inequality.

**11.** Show that the sequence x_n = 1/n converges to 0 in ℝ with the standard metric.

**12.** Is ℚ complete with the standard metric? Justify.

**13.** Prove that a convergent sequence in a metric space is Cauchy.

## Topology (Problems 14-17)

**14.** Prove that the union of any collection of open sets is open.

**15.** Show that [0, 1] is compact in ℝ using the Heine-Borel theorem.

**16.** Determine if (0, 1) is compact. If not, find an open cover with no finite subcover.

**17.** Prove that a continuous image of a compact set is compact.

## Analysis (Problems 18-21)

**18.** Prove the Bolzano-Weierstrass theorem for ℝ: every bounded sequence has a convergent subsequence.

**19.** Show that the series Σ1/n² converges. (Hint: Compare to an integral.)

**20.** Prove that uniform convergence preserves continuity.

**21.** Find the radius of convergence for Σ x^n/n!.

## Connections (Problems 22-25)

**22.** Explain how the fundamental group distinguishes a sphere from a torus.

**23.** State the connection between the Riemann zeta function and prime numbers.

**24.** How does the Lebesgue integral extend the Riemann integral? Give a function that is Lebesgue integrable but not Riemann integrable.

**25.** Describe how linear algebra and calculus combine in differential geometry.
