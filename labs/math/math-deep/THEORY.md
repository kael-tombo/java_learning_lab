# Advanced Mathematics Theory

## 1. Abstract Algebra: Groups
A **group** (G, ∗) is a set with a binary operation satisfying:
- **Closure:** a ∗ b ∈ G for all a, b ∈ G
- **Associativity:** (a ∗ b) ∗ c = a ∗ (b ∗ c)
- **Identity:** ∃e ∈ G such that e ∗ a = a ∗ e = a
- **Inverse:** ∀a ∈ G, ∃a⁻¹ with a ∗ a⁻¹ = e

**Abelian (commutative) group:** a ∗ b = b ∗ a for all a, b.

**Examples:**
- (ℤ, +): integers under addition
- (ℝ*, ·): non-zero reals under multiplication
- S_n: permutations of n elements under composition
- GL(n, ℝ): invertible n×n matrices under multiplication

**Subgroups:** H ⊆ G that is itself a group under the same operation.

**Lagrange's Theorem:** For finite group G and subgroup H, |H| divides |G|.

**Cyclic groups:** Generated by a single element: G = {g^n : n ∈ ℤ}.

**Group homomorphism:** φ: G → H with φ(ab) = φ(a)φ(b). Isomorphism = bijective homomorphism.

## 2. Rings and Fields
A **ring** (R, +, ·) has two operations:
- (R, +) is an abelian group
- (R, ·) is a monoid (associative with identity)
- Multiplication distributes over addition

**Commutative ring:** Multiplication is commutative.
**Ring with unity:** Multiplicative identity exists.

**Field:** A commutative ring with unity where every non-zero element has a multiplicative inverse.

**Examples:**
- ℤ: ring but not field (no multiplicative inverses)
- ℚ, ℝ, ℂ: fields
- ℤ/nℤ: field iff n is prime
- ℝ[x]: polynomial ring

**Ideal:** I ⊆ R such that (I, +) is a subgroup and r·i ∈ I for all r ∈ R, i ∈ I.

**Quotient ring R/I:** Cosets of I with induced operations.

## 3. Real Analysis: Metric Spaces
A **metric space** (X, d) has a distance function d: X × X → ℝ satisfying:
- d(x, y) ≥ 0, equality iff x = y
- d(x, y) = d(y, x) (symmetry)
- d(x, z) ≤ d(x, y) + d(y, z) (triangle inequality)

**Open ball:** B(x, r) = {y : d(x, y) < r}

**Open set:** U is open if every point has a ball contained in U.

**Convergence:** x_n → x if d(x_n, x) → 0.

**Cauchy sequence:** ∀ε > 0, ∃N such that d(x_m, x_n) < ε for m, n ≥ N.

**Complete space:** Every Cauchy sequence converges. ℝ is complete; ℚ is not.

**Continuous function:** f is continuous at x if ∀ε > 0, ∃δ > 0 with d(x, y) < δ ⟹ d(f(x), f(y)) < ε.

## 4. Topology Basics
A **topology** on X is a collection τ of subsets (open sets) such that:
- ∅, X ∈ τ
- Arbitrary unions of open sets are open
- Finite intersections of open sets are open

**Topological space:** (X, τ).

**Basis:** A collection B such that every open set is a union of basis elements.

**Key concepts:**
- **Closed set:** Complement is open
- **Closure:** Smallest closed set containing A
- **Interior:** Largest open set contained in A
- **Boundary:** Closure minus interior
- **Dense:** Closure equals whole space

**Compactness:** Every open cover has a finite subcover. In ℝ^n: closed and bounded (Heine-Borel).

**Connectedness:** Cannot be split into two disjoint non-empty open sets.

**Homeomorphism:** Continuous bijection with continuous inverse; preserves topological properties.

## 5. Sequences and Series in Analysis
**Monotone convergence:** Bounded monotone sequences converge in ℝ.

**Bolzano-Weierstrass:** Every bounded sequence in ℝ^n has a convergent subsequence.

**Uniform convergence:** f_n → f uniformly if sup|f_n(x) - f(x)| → 0. Preserves continuity and allows term-by-term integration.

**Power series:** Σ a_n(x-c)^n converges within its radius of convergence R = 1/limsup|a_n|^(1/n).

## 6. Measure Theory (Introduction)
A **measure** μ assigns sizes to sets:
- μ(∅) = 0
- Countable additivity: μ(∪A_n) = Σμ(A_n) for disjoint sets

**Lebesgue measure:** Extends length/area/volume to more sets than Riemann theory allows.

**Lebesgue integral:** Integrates more functions than Riemann; dominated convergence theorem.

**σ-algebra:** Collection of sets closed under complement and countable unions.

## 7. Connections Across Domains
- **Algebraic topology:** Uses groups to classify spaces (fundamental group, homology)
- **Functional analysis:** Vector spaces with topology (Banach, Hilbert spaces)
- **Algebraic geometry:** Studies zeros of polynomial systems using ring theory
- **Analytic number theory:** Uses analysis to study primes (Riemann zeta function)
- **Differential geometry:** Combines calculus and linear algebra on curved spaces
