# VISION — Arithmetic: Foundations for Computational Thinking
> Where this lab takes you: from raw number sense to reliable exact computation.

## The Arc
1. **Foundations** — place value, integer ops, order of operations, fractions & decimals.
2. **Fluency** — fast exact arithmetic, ratios, percentages, modular basics.
3. **Discrimination** — choose exact (BigInteger) vs floating point deliberately.
4. **Scale** — overflow-aware algorithms, digit DP, base conversions.
5. **Production** — money, counters, IDs: never lose a cent or overflow a counter.

## Milestones (checkable)
- [ ] M1: compute `17 * 19`, `1/8 + 5/6` exactly by hand in <60s.
- [ ] M2: explain why `0.1 + 0.2 != 0.3` in IEEE-754.
- [ ] M3: implement add/subtract/multiply on BigInteger without libraries.
- [ ] M4: detect overflow in `a + b` for ints with one comparison.
- [ ] M5: write a percent-discount function correct to the cent.

## Anti-Goals
- Reaching for `double` for currency; trusting `int` overflow "never happens".

## Interview Lens
- "Add two strings as numbers" — carry logic. "Is `/` integer or exact?"
