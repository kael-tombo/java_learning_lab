# VISION — Combinatorics: Counting Mastery Path
> Where this lab takes you: from "how many ways?" to exact enumeration.

## The Arc
1. **Foundations** — multiplication/addition principles, permutations, combinations.
2. **Fluency** — nPr/nCr by hand, stars-and-bars, pigeonhole.
3. **Discrimination** — ordered vs unordered; distinct vs repetition allowed.
4. **Scale** — inclusion–exclusion, Catalan numbers, binomial identities.
5. **Production** — capacity planning, test-case coverage analysis, lottery-style audits.

## Milestones (checkable)
- [ ] M1: compute C(10,3), P(10,3) and state what each counts.
- [ ] M2: stars-and-bars count of positive integer solutions to x+y+z=12.
- [ ] M3: prove pigeonhole application: 13 people → 2 share a birth month.
- [ ] M4: evaluate C(5,0)+C(5,1)+…+C(5,5) two ways.
- [ ] M5: count binary strings with no consecutive 1s (recurrence).

## Anti-Goals
- Using C when order matters; overflowing factorials (use multiplicative formula).

## Interview Lens
- "Count subsets?" "How many paths on a grid?" — C(m+n, m).
