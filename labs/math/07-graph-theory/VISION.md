# VISION — Graph Theory Mastery Path
> Where this lab takes you: from dots and lines to reachability and optimality.

## The Arc
1. **Foundations** — vertices, edges, degree, paths, cycles, trees.
2. **Fluency** — BFS/DFS, connected components, topological order.
3. **Discrimination** — which traversal/algorithm fits the question asked.
4. **Scale** — shortest paths, spanning trees, flows, planarity basics.
5. **Production** — dependency graphs, routing, social graphs, build systems.

## Milestones (checkable)
- [ ] M1: traverse a graph with BFS and DFS; state their visit orders.
- [ ] M2: count connected components in an undirected graph.
- [ ] M3: detect a cycle in directed and undirected graphs.
- [ ] M4: run Dijkstra on a 6-node weighted graph by hand.
- [ ] M5: explain when BFS replaces Dijkstra (unweighted).

## Anti-Goals
- Assuming Dijkstra works with negative edges; ignoring recursion depth on DFS.

## Interview Lens
- "Course prerequisites valid?" — topo sort. "Two nodes connected?" — BFS/union-find.
