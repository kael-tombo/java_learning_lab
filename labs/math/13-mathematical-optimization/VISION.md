# VISION — Mathematical Optimization Mastery Path
> Where this lab takes you: from "try harder" to principled search for the best.

## The Arc
1. **Foundations** — objective/constraints, feasible sets, local vs global optima.
2. **Fluency** — gradient descent mechanics, step-size intuition, convergence reads.
3. **Discrimination** — convex vs non-convex; when to pick GD vs stochastic vs line search.
4. **Scale** — momentum/Adam intuition, L-BFGS awareness, constrained basics.
5. **Production** — training loops, hyperparameter sweeps, when to stop.

## Milestones (checkable)
- [ ] M1: run gradient descent on f(x)=x² from x=10 and plot iterates.
- [ ] M2: show f(x,y)=x²−y² has a saddle, not a minimum.
- [ ] M3: explain step-size too large → divergence with a numeric demo.
- [ ] M4: tune LRs {1e-3, 1e-2, 1e-1} and record loss curves.
- [ ] M5: state when convexity makes GD guarantees safe.
