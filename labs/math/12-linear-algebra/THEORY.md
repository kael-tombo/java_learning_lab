# Linear Algebra

The study of vectors, matrices, and linear transformations.

## Scope

Vectors, matrices, eigenvalues, SVD, QR decomposition, linear transformations

## Java Implementation

The linear algebra package (com.math12) provides production-quality implementations.

## Prerequisites

- Strong foundation in high-school mathematics
- Java 21+ programming experience
- Familiarity with algorithmic thinking

## How to Use This Lab

1. Read THEORY.md for comprehensive mathematical treatment
2. Review MATH_FOUNDATION.md for prerequisite review
3. Study CODE_DEEP_DIVE.md for implementation patterns
4. Complete EXERCISES.md problem sets
5. Build the MINI_PROJECT for hands-on application
6. Challenge yourself with the REAL_WORLD_PROJECT

## Time Estimate
- Theory study: 2 hours
- Code implementation: 2.5 hours
- Exercises: 2 hours
- Projects: 3 hours
- **Total: ~9.5 hours**

## Difficulty: ★★★★☆ (Advanced)
