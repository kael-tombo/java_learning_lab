# VISION — Linear Algebra Mastery Path
> Where this lab takes you: from rows and columns to transformations of space.

## The Arc
1. **Foundations** — vectors, matrices, matrix ops, linear combinations, span.
2. **Fluency** — solving systems, row reduction (RREF), determinants 2x2/3x3.
3. **Discrimination** — rank vs nullity; when inverse exists; det==0 implications.
4. **Scale** — eigenvalues/eigenvectors, orthogonality, least squares.
5. **Production** — embeddings, graphics transforms, regression, PCA awareness.

## Milestones (checkable)
- [ ] M1: row-reduce a 3x3 to RREF by hand.
- [ ] M2: compute det of a 3x3 and use it to decide invertibility.
- [ ] M3: find eigenvalues/eigenvectors of a 2x2.
- [ ] M4: solve Ax=b and least-squares min ||Ax-b|| numerically.
- [ ] M5: explain what PCA's top eigenvector represents geometrically.

## Anti-Goals
- Assuming matrices commute (`AB=BA`); dividing by a matrix (use inverse/solve).

## Interview Lens
- "Why is Ax=b solvable iff b in col(A)?" "Fastest matvec for sparse A?"
