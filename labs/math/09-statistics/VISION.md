# VISION — Statistics Mastery Path
> Where this lab takes you: from averages to defensible inference.

## The Arc
1. **Foundations** — mean/median/mode, spread, boxplots, data types.
2. **Fluency** — z-scores, normal approximations, sampling distributions.
3. **Discrimination** — parametric vs non-parametric; significance vs effect size.
4. **Scale** — CIs, hypothesis tests, regression basics, correlation pitfalls.
5. **Production** — A/B reads, quality control, anomaly detection with stat backing.

## Milestones (checkable)
- [ ] M1: compute mean/median/IQR and explain when each wins.
- [ ] M2: build a 95% CI for a proportion by hand.
- [ ] M3: run a two-sample t-test and interpret p vs α.
- [ ] M4: explain why correlation ≠ causation with a confounder example.
- [ ] M5: chart a control chart and flag out-of-control points.

## Anti-Goals
- Reporting p<0.05 with tiny effect; trusting r as causation.

## Interview Lens
- "How many samples to detect a 2% lift?" — power analysis. "p-hacking?" — multiple looks.
