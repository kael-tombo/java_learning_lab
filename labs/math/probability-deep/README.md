# Probability Theory Deep Dive

## Overview
Master probability from axioms to applications: random variables, distributions, limit theorems, stochastic processes, and Bayesian inference.

## Prerequisites
- Calculus (integration essential)
- Basic combinatorics
- Comfort with mathematical notation

## Learning Objectives
1. Compute probabilities using axioms and counting
2. Work with discrete and continuous random variables
3. Apply expectation, variance, and moment generating functions
4. Use limit theorems (LLN, CLT) for approximation
5. Perform Bayesian inference and Markov chain analysis

## 10-Layer Curriculum
1. **THEORY.md** — Probability spaces, distributions, limit theorems
2. **EXERCISES.md** — 25+ practice problems with hints
3. **QUIZ.md** — 15-question assessment with answers
4. **FLASHCARDS.md** — 60 key term/definition pairs
5. **MATH_FOUNDATION.md** — Formal definitions and proofs
6. **CODE_DEEP_DIVE.md** — Simulations and computations in Python
7. **VISION.md** — Visual and intuitive interpretations
8. **MINI_PROJECT.md** — Build a probability distribution explorer
9. **REAL_WORLD_PROJECT.md** — A/B testing with Bayesian inference
10. **INDEX.md** — Navigation hub (already exists)
