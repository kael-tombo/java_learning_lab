# Linear Algebra Quiz

## Questions

**Q1.** The rank of a matrix equals:
- A) Number of rows  B) Number of columns  C) Dimension of column space  D) Determinant

**Q2.** If A is 3×3 and det(A) = 0, then:
- A) A is invertible  B) A has rank 3  C) A is singular  D) A is symmetric

**Q3.** The eigenvalues of a triangular matrix are:
- A) All zero  B) The diagonal entries  C) Always complex  D) The off-diagonal entries

**Q4.** For orthogonal matrix Q:
- A) Q^T = Q  B) Q^T = Q^(-1)  C) det(Q) = 0  D) Q^2 = 0

**Q5.** The product AB is defined when:
- A) A and B are square  B) Columns of A = rows of B  C) Rows of A = columns of B  D) A and B have same dimensions

**Q6.** A set of vectors is linearly independent if:
- A) No vector is a scalar multiple of another  B) The only zero combination is trivial  C) They span the space  D) They are orthogonal

**Q7.** The null space of A consists of:
- Vectors x where:
- A) Ax = b  B) Ax = 0  C) x^TA = 0  D) x = 0

**Q8.** The SVD of A expresses it as:
- A) A = LU  B) A = QR  C) A = UΣV^T  D) A = PDP^(-1)

**Q9.** The trace of a matrix equals:
- A) Product of eigenvalues  B) Sum of eigenvalues  C) Determinant  D) Rank

**Q10.** If A is symmetric, its eigenvectors are:
- A) Always parallel  B) Orthogonal  C) Always unit length  D) Non-existent

**Q11.** The dimension of the column space plus the dimension of the null space equals:
- A) Number of rows  B) Number of columns  C) Rank  D) Trace

**Q12.** A projection matrix P satisfies:
- A) P² = P  B) P² = I  C) P² = 0  D) P² = -P

**Q13.** The pseudoinverse A⁺ is computed via SVD as:
- A) UΣV^T  B) VΣ⁺U^T  C) U^TΣV  D) Σ⁺U^TV

**Q14.** PCA finds directions of:
- A) Minimum variance  B) Maximum variance  C) Zero covariance  D) Equal variance

**Q15.** Two matrices are similar if:
- A) A = B  B) B = P^(-1)AP  C) A and B have same entries  D) A^T = B

## Answer Key

1. **C** — Rank = dimension of column space.
2. **C** — det = 0 means singular (non-invertible).
3. **B** — Triangular matrix eigenvalues are diagonal entries.
4. **B** — Orthogonal: Q^T = Q^(-1).
5. **B** — Inner dimensions must match.
6. **B** — Trivial combination only.
7. **B** — Null space: Ax = 0.
8. **C** — SVD: A = UΣV^T.
9. **B** — Trace = sum of eigenvalues.
10. **B** — Symmetric matrices have orthogonal eigenvectors.
11. **B** — Rank-nullity theorem: rank + nullity = n.
12. **A** — Projection matrices are idempotent.
13. **B** — Pseudoinverse: VΣ⁺U^T.
14. **B** — PCA maximizes variance.
15. **B** — Similarity: B = P^(-1)AP.
