# Linear Algebra Deep Dive

## Overview
Master vectors, matrices, linear transformations, eigenvalues, and their applications in computer science and data science.

## Prerequisites
- Algebra and basic geometry
- Familiarity with functions and equations
- Some programming experience (Python recommended)

## Learning Objectives
1. Perform matrix operations fluently
2. Solve systems of linear equations
3. Understand vector spaces and linear independence
4. Compute eigenvalues and eigenvectors
5. Apply SVD and PCA to real data

## 10-Layer Curriculum
1. **THEORY.md** — Vectors, matrices, transformations, decompositions
2. **EXERCISES.md** — 25+ practice problems with hints
3. **QUIZ.md** — 15-question assessment with answers
4. **FLASHCARDS.md** — 60 key term/definition pairs
5. **MATH_FOUNDATION.md** — Formal definitions and proofs
6. **CODE_DEEP_DIVE.md** — NumPy implementations and algorithms
7. **VISION.md** — Geometric interpretations
8. **MINI_PROJECT.md** — Build a matrix calculator
9. **REAL_WORLD_PROJECT.md** — Image compression with SVD
10. **INDEX.md** — Navigation hub (already exists)

## Time Estimate
- Theory study: 10-12 hours
- Exercises: 8-10 hours
- Projects: 5-7 hours
- Total: ~25 hours
