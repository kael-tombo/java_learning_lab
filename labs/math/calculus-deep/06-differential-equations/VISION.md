# VISION — Differential Equations
> From y' = ky to modeling real change.

## Arc
1. **Foundations** — terminology, order, initial conditions.
2. **Fluency** — separable equations, y' = ky, exponential growth/decay.
3. **Discrimination** — separable vs linear first-order; stability of equilibria.
4. **Scale** — integrating factors, logistic model.
5. **Production** — numeric stepping (Euler/RK) when no closed form exists.

## Milestones
- [ ] M1: solve dy/dx = ky, y(0)=y₀.
- [ ] M2: solve y' + y = 0 via separation.
- [ ] M3: identify equilibrium solutions of y' = y(1−y).
- [ ] M4: step Euler on y' = −y from y=1 with h=0.1.
- [ ] M5: explain when a model needs numerics over a formula.

## Anti-Goals
- Separating variables without checking the domain split; Euler with huge h.
