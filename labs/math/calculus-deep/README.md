# Calculus Deep Dive

## Overview
Master the mathematics of change: limits, derivatives, integrals, and infinite series with computational intuition.

## Prerequisites
- Algebra and trigonometry fluency
- Comfort with functions, graphs, and notation
- Basic programming skills (Python recommended)

## Learning Objectives
1. Compute limits analytically and numerically
2. Apply derivative rules to real functions
3. Evaluate definite and indefinite integrals
4. Analyze infinite series convergence
5. Connect calculus to optimization and physics

## 10-Layer Curriculum
1. **THEORY.md** — Limits, derivatives, integrals, series
2. **EXERCISES.md** — 25+ practice problems with hints
3. **QUIZ.md** — 15-question assessment with answers
4. **FLASHCARDS.md** — 60 key term/definition pairs
5. **MATH_FOUNDATION.md** — Formal definitions and proofs
6. **CODE_DEEP_DIVE.md** — Numerical methods in Python
7. **VISION.md** — Geometric and physical interpretations
8. **MINI_PROJECT.md** — Build a derivative calculator
9. **REAL_WORLD_PROJECT.md** — Physics simulation engine
10. **INDEX.md** — Navigation hub (already exists)

## Time Estimate
- Theory study: 8-10 hours
- Exercises: 6-8 hours
- Projects: 4-6 hours
- Total: ~20 hours
