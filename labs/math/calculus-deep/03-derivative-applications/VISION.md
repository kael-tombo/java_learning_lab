# VISION — Derivative Applications
> Using derivatives to optimize, approximate, and classify.

## Arc
1. **Foundations** — critical points, increasing/decreasing, first-derivative test.
2. **Fluency** — second-derivative/concavity test; absolute extrema on closed intervals.
3. **Discrimination** — max vs min vs saddle vs inflection.
4. **Scale** — related rates, optimization word problems, L'Hôpital.
5. **Production** — error via differentials; sensitivity of a computed quantity.
