# VISION — Integration Techniques
> Choosing the right trick for a hard integral.

## Arc
1. **Foundations** — u-sub, trigonometric substitution.
2. **Fluency** — integration by parts, partial fractions.
3. **Discrimination** — which technique fits; when to combine.
4. **Scale** — improper integrals, comparison tests.
5. **Production** — recognizing when a numeric answer is the only answer.
