A graduate continues operating through degraded conditions, no panic.
A graduate measures backend security hardening outcomes instead of asserting them.

## What this lab will not teach

This backend security hardening lab deliberately leaves the following out.
- Cryptographic primitive design stays outside this build.
- Red-team penetration operations stays outside the course.
- Digital-forensics investigation stays outside this lab.
Meeting those needs belongs to neighboring backend security hardening studies.
