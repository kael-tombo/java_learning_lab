## What this lab will not teach

This Spring Cloud coordination lab deliberately leaves the following out.
- Kubernetes operator development stays outside this build.
- Service-mesh data-plane tuning stays outside the course.
- Multi-cloud networking design stays outside this lab.
Meeting those needs belongs to neighboring Spring Cloud coordination studies.
