# VISION — Spring Boot Basics

> From first `@SpringBootApplication` to confident production deploys.

## The Arc
1. **Bootstrap** — understand starters, auto-configuration, embedded servers.
2. **Configuration** — property precedence, profiles, `@ConfigurationProperties`.
3. **Actuator** — health, metrics, a custom endpoint.
4. **Testing** — `@SpringBootTest`, slices, mock MVC.
5. **Production** — graceful shutdown, packaging, Docker.

## Milestones (checkable)
- [ ] M1: Run an app on a custom port with a profile-specific property.
- [ ] M2: Explain why a bean was (or wasn't) auto-configured.
- [ ] M3: Expose `/actuator/health` and a custom info endpoint.
- [ ] M4: Slice-test a controller with `@WebMvcTest`.
- [ ] M5: Package a runnable jar and trim it with layered dependencies.

## Anti-Goals
- Treating `@SpringBootApplication` as magic; copying pom.xml blindly.

## Interview Lens
- "How does Spring Boot auto-configure a DataSource?"
- "Order the property sources from lowest to highest precedence."
