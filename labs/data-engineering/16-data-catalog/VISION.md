# VISION — Data Catalogs: Discovery That People Actually Use
> Where this lab takes you: from a spreadsheet of table names to a searchable,
  lineage-aware catalog that answers "what is this and can I use it".

## The Arc
1. **Register** — technical metadata, descriptions, glossary terms.
2. **Discover** — search, tags, ownership, quality signals, top users.
3. **Understand** — lineage, impact, column-level semantics.
4. **Trust** — certifications, freshness, deprecation, review expiry.
5. **Adopt** — integrations, APIs, and changing behaviour without mandating it.

## Milestones (checkable)
- [ ] M1: build a registry that ingests metadata from 3 engines automatically.
- [ ] M2: implement search that finds a table by business term, not table name.
- [ ] M3: build a lineage graph with column-level propagation.
- [ ] M4: design a certification + deprecation lifecycle with real dates.
- [ ] M5: instrument the catalog and prove it is used (not just deployed).

## Anti-Goals
- A catalog that requires a human to type the same metadata the engine knows.
- Descriptions added once and never updated.
- A search that only matches exact identifiers.

## Interview Lens
- "How do you know a table is safe to use?"
- "Who owns this, and how would I find out?"
- "What happens when a table is deprecated?"
