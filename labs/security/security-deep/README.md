# security-deep

## Topic

Advanced security micro-labs: cryptography, OAuth2/OIDC, penetration testing, SAST/DAST, container security, API security, identity management, zero trust

## Overview

Security Deep Academy provides intensive, hands-on micro-labs for mastering advanced security engineering concepts using Java, Spring Security, and modern DevSecOps tooling.

## Prerequisites

- Java 17+
- Spring Boot 3.x
- Maven or Gradle
- Docker & Kubernetes basics
- Familiarity with OWASP Top 10
- Command-line proficiency

## Learning Objectives

- Implement cryptographic primitives from first principles
- Design and audit OAuth2/OIDC authorization flows
- Perform structured penetration testing and vulnerability classification
- Integrate SAST/DAST into CI/CD pipelines
- Harden container images and Kubernetes workloads
- Apply Zero Trust architecture patterns
- Build defense-in-depth into every layer of an application

## Lab Structure

Each micro-lab contains:

- **src/** - Java source code for hands-on implementation
- **GUIDE.md** - Step-by-step walkthrough
- **EXERCISES.md** - Practice problems
- **QUIZ.md** - Knowledge checks
- **FLASHCARDS.md** - Spaced repetition cards
- **INTERVIEW.md** - Common interview questions
- **MOCK_INTERVIEW.md** - Simulated interview scenarios
- **PROBLEM_WALKTHROUGH.md** - Detailed problem solutions

## Micro-Labs

| # | Lab | Focus |

| 1 | Cryptography Deep | AES, RSA, DH, ECC, signatures |

## Assessment

Complete all exercises, quizzes, and flashcards. Build the mini-project and real-world project to demonstrate mastery.
