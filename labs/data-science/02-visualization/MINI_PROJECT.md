# Visualization - Mini Project: Six-chart transit story
## Challenge
Build the Six-chart transit story for 02-visualization in one sitting: two transit lines over eight quarters in a hand table.
Scope stays tight so the 02-visualization technique itself is what gets practiced.
## Dataset
Working set for 02-visualization: two transit lines over eight quarters in a hand table.
Reference methods: histograms, small multiples, slope comparisons, captioned line/bar discipline.
## Steps
1. Draw the raw quarterly lines first with gap marked for 02-visualization.
2. Add one bar comparison with zero-baseline y for 02-visualization.
3. Rescale experiment showing why truncated axes mislead for 02-visualization.
4. Caption every chart with counts and source line for 02-visualization.
## Complete when
- bar y-axis starts at zero and is labeled within the 02-visualization mini submission.
- gap quarter visibly marked not interpolated over verified by rerunning 02-visualization commands.
- each caption names row counts used readable inside the 02-visualization mini report.
- one rejected chart listed with reason confirmed before calling 02-visualization mini done.
