# Data Pipelines - Mini Project: Two-stage local pipeline
## Challenge
Build the Two-stage local pipeline for 15-data-pipelines in one sitting: three daily CSV drops plus one product list.
Scope stays tight so the 15-data-pipelines technique itself is what gets practiced.
## Dataset
Working set for 15-data-pipelines: three daily CSV drops plus one product list.
Reference methods: ingest/validate/version staging, idempotent loads, schema tests, backfill replay.
## Steps
1. Stage each drop under dated folders untouched for 15-data-pipelines.
2. Validate headers and id uniqueness per drop for 15-data-pipelines.
3. Build one joined fact table idempotently for 15-data-pipelines.
4. Rerun day two and prove no duplication for 15-data-pipelines.
## Complete when
- dated staging folders listed in README within the 15-data-pipelines mini submission.
- validation failures logged with row numbers verified by rerunning 15-data-pipelines commands.
- rerun row-count proof present readable inside the 15-data-pipelines mini report.
- join key misses counted explicitly confirmed before calling 15-data-pipelines mini done.
