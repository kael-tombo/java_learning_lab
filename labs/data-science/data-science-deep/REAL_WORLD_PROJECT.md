# Data Science Deep — Real-World Project: Portfolio Dossier

Produce one portfolio-grade dossier on an open tabular dataset of your
choice: registered question, grain, and decision the analysis would
inform; a wrangling audit (missingness, types, rejects logged);
exploratory analysis with counts on every claim; a baseline model with
locked-test evaluation; and a refresh plan stating what would trigger
re-runs and what would invalidate the conclusions.

Acceptance: a reviewer reruns the full flow from raw files to final
tables with no missing steps; the evaluation card states split
protocol, threshold, prevalence, and calibration posture; limitations
are written before praise; the refresh plan names owners and triggers,
not just intentions. This dossier is the reference other learners
point at when asking what "done" looks like — build it to be pointed at.
