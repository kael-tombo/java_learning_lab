# Data Science Deep — Mini Project: Vertical Slice in a Week

Take a 1k–10k-row open dataset (documented license) from raw file to
finished brief in one week of evenings: one cleaning pass with a
logged reject list, two charts with message titles, one baseline model
with a locked test split, one evaluation card (metrics with counts,
threshold stated, caveats listed).

Constraints that make it real: the test split is frozen before the
first model trains; every number in the brief traces to a script that
reproduces it; the brief ends with a "what could still be wrong"
section of at least three items. If any step can't be rerun from
scratch, that step — not the analysis — is the week's main finding.
