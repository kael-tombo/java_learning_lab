# Descriptive Statistics - Visual Guide

## Dot plot of {3, 7, 7, 9, 12, 15, 21}

```text
 3  7  7  9  12 15       21
 *  *  *  *  *  *        *
         |median 9.0
                |mean 10.57 (pulled right by 21)
```

## Five-number summary as a box

```text
min   Q1  med  Q3   max
3-----7----9---13.5--21
|< IQR = 6.5 >|
right whisker longer: right skew, matches skew +0.58
```

## n vs n - 1 spread picture

```text
ss = 215.71 fixed stick; two ways to cut it:
pop  [/7  = 30.82] sd 5.55   (describe these seven)
samp [/6  = 35.95] sd 6.00   (estimate the source)
sample cut is wider: pays for the fitted mean
```

## Skew sign gallery

```text
left skew:  mean < median, tail stretches left
symmetric:  mean = median (roughly), tails match
right skew: mean 10.57 > median 9.0, tail stretches right (this lab)
```

## Correlation ladder (lab r = 0.99)

```text
r = -1  perfect falling line
r =  0  no linear pattern (curves still possible)
r = +1  perfect rising line
0.99    points hug a rising line; check scatter for curvature/outliers
```

## Kurtosis intuition

```text
excess < 0 (-0.62 here): mild tails, flat-ish top
excess = 0: normal-like tails
excess > 0: heavy tails, outliers expected
```
