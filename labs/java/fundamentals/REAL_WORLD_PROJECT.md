# Real-World Project — Java Fundamentals (fundamentals)

Production-style build around syntax, OOP, JVM, classpath: design, scale, operate.

## Problem statement
Design a service/demo where types & operators, control flow, OOP pillars are load-bearing. Must handle restarts, bad input, and load.

## Architecture
- `types & operators` → component + owner + SLO.
- `control flow` → component + owner + SLO.
- `OOP pillars` → component + owner + SLO.
- `exceptions` → component + owner + SLO.
- `generics intro` → component + owner + SLO.

## Milestones (4)
1. Slice: happy path + test.
2. Harden: timeouts, retries, validation.
3. Observe: logs/metrics/JFR + dashboard.
4. Scale: benchmark + tune one bottleneck.

## Ops checklist
- [ ] Dockerfile + health check
- [ ] Load test (k6/JMeter) with p99
- [ ] Runbook: top-3 failures + mitigations

## Interview story
Prepare STAR: problem → approach → metric → lesson.
