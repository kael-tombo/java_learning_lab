# Mini Project — Java Fundamentals (fundamentals)

Build in 2–4h: small app exercising syntax, OOP, JVM, classpath.

## Goal
A CLI/demo app that uses at least 4 of: types & operators, control flow, OOP pillars, exceptions.

## Requirements
- [ ] Use `types & operators` with a visible behavior/test.
- [ ] Use `control flow` with a visible behavior/test.
- [ ] Use `OOP pillars` with a visible behavior/test.
- [ ] Use `exceptions` with a visible behavior/test.
- [ ] Use `generics intro` with a visible behavior/test.
- [ ] Use `JVM & bytecode` with a visible behavior/test.
- [ ] 3+ JUnit tests green.
- [ ] README with run + sample output.

## Steps
1. Scaffold Maven module.
2. Implement core loop.
3. Add tests + one metric (time/heap/threads).
4. Demo script (5 min).
