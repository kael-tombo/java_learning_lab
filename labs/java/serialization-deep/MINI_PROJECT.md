# Mini Project — Deep Serialization (serialization-deep)

Build in 2–4h: small app exercising Java native, Jackson, Avro, Protobuf, versioning.

## Goal
A CLI/demo app that uses at least 4 of: Serializable & serialVersionUID, Externalizable, Jackson databind, Avro schemas.

## Requirements
- [ ] Use `Serializable & serialVersionUID` with a visible behavior/test.
- [ ] Use `Externalizable` with a visible behavior/test.
- [ ] Use `Jackson databind` with a visible behavior/test.
- [ ] Use `Avro schemas` with a visible behavior/test.
- [ ] Use `Protobuf` with a visible behavior/test.
- [ ] Use `versioning & compatibility` with a visible behavior/test.
- [ ] 3+ JUnit tests green.
- [ ] README with run + sample output.

## Steps
1. Scaffold Maven module.
2. Implement core loop.
3. Add tests + one metric (time/heap/threads).
4. Demo script (5 min).
