# Mini Project — CSV Analytics (single pass)

## Goal
Top-5 products by revenue from 1M-row `orders.csv`, plus per-region counts. One pass.

## Input
`orderId,product,region,qty,price` — 1M rows generated by script.

## Steps
1. `Files.lines(p)` → map to record `Order(...)` (skip bad lines to DLQ).
2. Single `collect(teeing(...))`: revenue-by-product + count-by-region.
3. Top-5 via custom topK collector or post-sort of small map.
4. Time sequential vs parallel; assert same result.

## Skeleton
```java
record Order(String product, String region, int qty, double price) {}
var stats = Files.lines(p).skip(1).map(Order::parse)
  .collect(Collectors.teeing(
    groupingBy(Order::product, summingDouble(o -> o.qty()*o.price())),
    groupingBy(Order::region, counting()), Stats::new));
```

## Acceptance
- Correct on 1M rows; bad-line DLQ non-empty handled.
- Memory < 512MB; documents seq vs par ms.

## Stretch
- Sliding 7-day window gatherer; p99 order value.
