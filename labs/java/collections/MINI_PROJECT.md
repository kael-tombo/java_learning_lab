# Mini Project — Java Collections Fundamentals (collections)

Build in 2–4h: small app exercising List/Set/Map, equals/hashCode, sorting.

## Goal
A CLI/demo app that uses at least 4 of: ArrayList vs LinkedList, HashSet/TreeSet, HashMap internals, equals/hashCode contract.

## Requirements
- [ ] Use `ArrayList vs LinkedList` with a visible behavior/test.
- [ ] Use `HashSet/TreeSet` with a visible behavior/test.
- [ ] Use `HashMap internals` with a visible behavior/test.
- [ ] Use `equals/hashCode contract` with a visible behavior/test.
- [ ] Use `comparators` with a visible behavior/test.
- [ ] Use `streams basics` with a visible behavior/test.
- [ ] 3+ JUnit tests green.
- [ ] README with run + sample output.

## Steps
1. Scaffold Maven module.
2. Implement core loop.
3. Add tests + one metric (time/heap/threads).
4. Demo script (5 min).
