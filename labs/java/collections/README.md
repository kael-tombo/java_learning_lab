# Java Collections Fundamentals — collections

> Hands-on lab: List/Set/Map, equals/hashCode, sorting.

## Objectives
- Understand ArrayList vs LinkedList in Java 17+.
- Understand HashSet/TreeSet in Java 17+.
- Understand HashMap internals in Java 17+.
- Understand equals/hashCode contract in Java 17+.
- Run, measure, and explain every example.

## Layout
- `THEORY.md` — concepts (exists).
- `EXERCISES.md` — 8–10 hands-on labs.
- `QUIZ.md` — 20 self-check questions.
- `CODE_DEEP_DIVE.md` — annotated snippets.
- `MINI_PROJECT.md` / `REAL_WORLD_PROJECT.md` — builds.

## Prerequisites
- JDK 17+ (`java -version`), Maven 3.9+.
- IDE with debugger; JFR/JMC optional.
- This lab assumes `ArrayList vs LinkedList` basics.

## Quickstart
```bash
cd labs/java/collections
mvn -q test
```

## How to use
1. Read THEORY.md.
2. Do EXERCISES 1–4.
3. Attempt MINI_PROJECT.
4. Take QUIZ (aim 16/20).
