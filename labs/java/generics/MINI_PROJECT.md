# Mini Project — Java Generics Mastery (generics)

Build in 2–4h: small app exercising type params, wildcards, erasure, variance.

## Goal
A CLI/demo app that uses at least 4 of: type parameters & bounds, wildcards PECS, erasure & bridge methods, generic methods.

## Requirements
- [ ] Use `type parameters & bounds` with a visible behavior/test.
- [ ] Use `wildcards PECS` with a visible behavior/test.
- [ ] Use `erasure & bridge methods` with a visible behavior/test.
- [ ] Use `generic methods` with a visible behavior/test.
- [ ] Use `variance` with a visible behavior/test.
- [ ] Use `type tokens` with a visible behavior/test.
- [ ] 3+ JUnit tests green.
- [ ] README with run + sample output.

## Steps
1. Scaffold Maven module.
2. Implement core loop.
3. Add tests + one metric (time/heap/threads).
4. Demo script (5 min).
