# Algorithmic Patterns in Java — LEETCODE_SOLUTIONS

> Hands-on lab: arrays/strings/DP/graphs/two-pointers/sliding-window.

## Objectives
- Understand two pointers in Java 17+.
- Understand sliding window in Java 17+.
- Understand hashing in Java 17+.
- Understand binary search in Java 17+.
- Run, measure, and explain every example.

## Layout
- `THEORY.md` — concepts (exists).
- `EXERCISES.md` — 8–10 hands-on labs.
- `QUIZ.md` — 20 self-check questions.
- `CODE_DEEP_DIVE.md` — annotated snippets.
- `MINI_PROJECT.md` / `REAL_WORLD_PROJECT.md` — builds.

## Prerequisites
- JDK 17+ (`java -version`), Maven 3.9+.
- IDE with debugger; JFR/JMC optional.
- This lab assumes `two pointers` basics.

## Quickstart
```bash
cd labs/java/LEETCODE_SOLUTIONS
mvn -q test
```
