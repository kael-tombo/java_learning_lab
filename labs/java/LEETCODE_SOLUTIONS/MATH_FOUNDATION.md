# Math Foundation — Algorithmic Patterns in Java (LEETCODE_SOLUTIONS)

Quantitative models behind arrays/strings/DP/graphs/two-pointers/sliding-window. (LEETCODE_SOLUTIONS variant: complexity math.)

## Core formulas

- `T(n)=2T(n/2)+O(n) => O(n log n) (merge sort)`

- `Sliding window: O(n) vs O(n*k) brute`

- `DP knapsack: O(n*W) time, O(W) space`

- `BFS: O(V+E); Dijkstra: O((V+E) log V)`

- `Master theorem; amortized ArrayList add O(1)`

- `HashMap get O(1) avg, O(n) worst`

- `Binary search: log2(n) comparisons`

- `Top-K heap: O(n log k)`
