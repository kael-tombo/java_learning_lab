# Mini Project — Algorithmic Patterns in Java (LEETCODE_SOLUTIONS)

Build in 2–4h: small app exercising arrays/strings/DP/graphs/two-pointers/sliding-window.

## Goal
A CLI/demo app that uses at least 4 of: two pointers, sliding window, hashing, binary search.

## Requirements
- [ ] Use `two pointers` with a visible behavior/test.
- [ ] Use `sliding window` with a visible behavior/test.
- [ ] Use `hashing` with a visible behavior/test.
- [ ] Use `binary search` with a visible behavior/test.
- [ ] Use `DP knapsack/LIS` with a visible behavior/test.
- [ ] Use `graphs BFS/DFS` with a visible behavior/test.
- [ ] 3+ JUnit tests green.
- [ ] README with run + sample output.

## Steps
1. Scaffold Maven module.
2. Implement core loop.
3. Add tests + one metric (time/heap/threads).
4. Demo script (5 min).
