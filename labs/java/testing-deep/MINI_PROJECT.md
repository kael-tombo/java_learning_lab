# Mini Project — Deep Java Testing (testing-deep)

Build in 2–4h: small app exercising JUnit5, Mockito, AssertJ, Testcontainers.

## Goal
A CLI/demo app that uses at least 4 of: JUnit5 lifecycle & extensions, parameterized tests, Mockito stubbing/verification, AssertJ fluent assertions.

## Requirements
- [ ] Use `JUnit5 lifecycle & extensions` with a visible behavior/test.
- [ ] Use `parameterized tests` with a visible behavior/test.
- [ ] Use `Mockito stubbing/verification` with a visible behavior/test.
- [ ] Use `AssertJ fluent assertions` with a visible behavior/test.
- [ ] Use `Testcontainers` with a visible behavior/test.
- [ ] Use `mutation testing` with a visible behavior/test.
- [ ] 3+ JUnit tests green.
- [ ] README with run + sample output.

## Steps
1. Scaffold Maven module.
2. Implement core loop.
3. Add tests + one metric (time/heap/threads).
4. Demo script (5 min).
