# Mini Project — Modern Java 17-25 (modern-java)

Build in 2–4h: small app exercising records, sealed classes, pattern matching, virtual threads, switch expressions.

## Goal
A CLI/demo app that uses at least 4 of: records, sealed classes, pattern matching instanceof/switch, text blocks.

## Requirements
- [ ] Use `records` with a visible behavior/test.
- [ ] Use `sealed classes` with a visible behavior/test.
- [ ] Use `pattern matching instanceof/switch` with a visible behavior/test.
- [ ] Use `text blocks` with a visible behavior/test.
- [ ] Use `virtual threads` with a visible behavior/test.
- [ ] Use `structured concurrency` with a visible behavior/test.
- [ ] 3+ JUnit tests green.
- [ ] README with run + sample output.

## Steps
1. Scaffold Maven module.
2. Implement core loop.
3. Add tests + one metric (time/heap/threads).
4. Demo script (5 min).
