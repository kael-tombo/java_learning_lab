# Vision — Jakarta EE

## Direction
- EE 10/11: CDI-lite, virtual-thread-friendly, observability built in.
- Runtimes converge on cloud-native: fast boot, small images, Dev Services.
- MicroProfile patterns (health/metrics/config/FT) are baseline expectations.

## 5-Year Bets
1. Quarkus/OpenLiberty lead greenfield; WildFly modernizes existing estates.
2. Virtual threads become default request handling.
3. Native images for EE microservices go mainstream.

## Constants
- Spec portability matters less than runtime operability.
- Health/metrics/tracing non-negotiable.

## Signals
- Jakarta EE 11, MicroProfile 7, Quarkus 3.x releases.
- Spring 6/Boot 3 vs EE feature parity tracking.

## Career
Production EE (tx, sec, obs) is enterprise hiring moat. Ship the shop service.

## Anti-Vision
Don't gold-plate EJB remoting or SOAP unless legacy demands.
REST + messaging + JPA cover 95%.

## 30/60/90
- 30d: JAX-RS + CDI + validation.
- 60d: JPA + tx + security.
- 90d: shop service with dashboards.
