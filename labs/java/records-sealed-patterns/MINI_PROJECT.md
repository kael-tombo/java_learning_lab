# Mini Project — Records, Sealed Classes & Patterns (records-sealed-patterns)

Build in 2–4h: small app exercising data carriers, exhaustive switch, deconstruction.

## Goal
A CLI/demo app that uses at least 4 of: record canonical constructors, compact constructors, sealed permits, pattern matching switch.

## Requirements
- [ ] Use `record canonical constructors` with a visible behavior/test.
- [ ] Use `compact constructors` with a visible behavior/test.
- [ ] Use `sealed permits` with a visible behavior/test.
- [ ] Use `pattern matching switch` with a visible behavior/test.
- [ ] Use `guarded patterns` with a visible behavior/test.
- [ ] Use `record patterns` with a visible behavior/test.
- [ ] 3+ JUnit tests green.
- [ ] README with run + sample output.

## Steps
1. Scaffold Maven module.
2. Implement core loop.
3. Add tests + one metric (time/heap/threads).
4. Demo script (5 min).
