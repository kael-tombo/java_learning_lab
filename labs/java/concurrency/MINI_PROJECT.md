# Mini Project — Java Concurrency Basics (concurrency)

Build in 2–4h: small app exercising threads, locks, executors, atomics.

## Goal
A CLI/demo app that uses at least 4 of: Thread lifecycle, synchronized & volatile, Locks & conditions, Executors & pools.

## Requirements
- [ ] Use `Thread lifecycle` with a visible behavior/test.
- [ ] Use `synchronized & volatile` with a visible behavior/test.
- [ ] Use `Locks & conditions` with a visible behavior/test.
- [ ] Use `Executors & pools` with a visible behavior/test.
- [ ] Use `Futures & CompletableFuture` with a visible behavior/test.
- [ ] Use `atomics` with a visible behavior/test.
- [ ] 3+ JUnit tests green.
- [ ] README with run + sample output.

## Steps
1. Scaffold Maven module.
2. Implement core loop.
3. Add tests + one metric (time/heap/threads).
4. Demo script (5 min).
