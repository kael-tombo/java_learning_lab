# References: Bytecode Generation

## Specifications and JEPs

- JEP 457 — *Class-File API (Preview)*, Java 22: `ClassFile.of()`,
  `ClassModel`, builders, transforms (first preview).
- JEP 466 — *Class-File API (Second Preview)*, Java 23: refined
  code-builder and transform surface — the rig this lab pins
  (`--release 23 --enable-preview`).
- JVMS SE 23, §4 — the struct being read and written (header, pool,
  `Code`, `StackMapTable`); §4.10 — what generated output must verify.
- JVMS SE 23, §5 — `defineClass` verification of generated bytes.

## ASM lineage (concept source)

- ASM (OW2, since 2002): `ClassReader`/`ClassVisitor`/
  `ClassWriter`, `COMPUTE_MAXS`/`COMPUTE_FRAMES`, `Opcodes.ASM9`
  gates, `ClassNode` tree API. User guide and Javadoc at the OW2
  ASM site — the vocabulary (`visitMethod` returning null to drop)
  this lab maps to withhold-transforms.
- ByteBuddy (2014, Rafael Winterhalter): fluent DSL over ASM;
  demonstrates the emitter-factoring pattern of REFACTORING.md §3
  at production scale.

## OpenJDK source

- `src/java.base/share/classes/java/lang/classfile/ClassFile.java`
  (factory, `parse`/`build`/`transform`), `ClassModel.java`,
  `MethodModel.java`, `CodeBuilder.java` (instruction + label surface),
  `Label.java`.
- `src/java.base/share/classes/java/lang/constant/MethodTypeDesc.java`
  and `ConstantDescs.java` (`CD_int` and peers used in every build).
- `src/java.base/share/classes/java/lang/invoke/MethodHandles.java`
  (`lookup().defineClass` loading path for generated bytes).

## Reading order

JEP 457 (motivation + operation graph) first, then the `CodeBuilder`
Javadoc (instruction/label calls), then the ASM user guide's visitor
chapter for the concept map. Keep JVMS §4.7.3 open: every builder
call ultimately writes a `Code` attribute.
