# Mini Project — Deep Collections Engineering (collections-deep)

Build in 2–4h: small app exercising hashing, trees, concurrent maps, custom structures.

## Goal
A CLI/demo app that uses at least 4 of: hash spreading & bins, red-black trees, ConcurrentHashMap, CopyOnWriteArrayList.

## Requirements
- [ ] Use `hash spreading & bins` with a visible behavior/test.
- [ ] Use `red-black trees` with a visible behavior/test.
- [ ] Use `ConcurrentHashMap` with a visible behavior/test.
- [ ] Use `CopyOnWriteArrayList` with a visible behavior/test.
- [ ] Use `immutable collections` with a visible behavior/test.
- [ ] Use `Deque & queues` with a visible behavior/test.
- [ ] 3+ JUnit tests green.
- [ ] README with run + sample output.

## Steps
1. Scaffold Maven module.
2. Implement core loop.
3. Add tests + one metric (time/heap/threads).
4. Demo script (5 min).
