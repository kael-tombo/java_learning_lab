# EXERCISES — Lists Deep

1. Implement a dynamic array with doubling growth; verify amortized add.
2. Trace ArrayList.grow at size 10, 11, 15, 16.
3. Implement a doubly-linked list addFirst/addLast with a sentinel.
4. Reverse a singly-linked list in place; trace pointers.
5. Detect a cycle with Floyd; find entry node.
6. Implement LinkedList iterator remove without extra pass.
7. Time Vector vs ArrayList vs CopyOnWriteArrayList for read-heavy.
8. Merge two sorted LinkedLists into one without new nodes.
9. Implement LRU with LinkedHashMap vs hand-rolled.
10. Show Why LinkedList beats ArrayList only in middle iteration-remove.
11. Write a test that triggers ConcurrentModificationException.
12. Implement a partition of a linked list around x.
13. Design a stack on top of LinkedList with no extra fields.
14. Compare ArrayDeque vs LinkedList for a deque workload.
15. Pick a list for 5 workloads: mostly-append, mostly-front-pop, random-access, iteration-removal, concurrent readers.
