# maps-deep — Overview

The Java Map family in depth: HashMap, TreeMap, LinkedHashMap, ConcurrentHashMap, plus a Bloom-filter "map-like" membership structure.

## Labs
- 01-hashmap-deep — hash buckets, treeification, resize
- 02-treemap-deep — red-black ordered map
- 03-linkedhashmap-deep — insertion/access order
- 04-concurrenthashmap-deep — Java 8+ concurrent map
- 05-bloomfilter-deep — probabilistic membership

## Learning path
1. Hash function → bucket index → collision strategy.
2. Resize and load factor.
3. Order views and iteration semantics.
4. Concurrency: bin locks vs the old segment locks.
