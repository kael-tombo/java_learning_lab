# data-structures-advanced — Overview

A survey of advanced data structures: probabilistic filters, range structures, linking structures.

## Labs
- 01/02/... variants of: bloom-filter, fenwick-tree, merkle-tree, red-black-tree, segment-tree, skip-list, suffix-array, treap, trie, union-find
- Many subdirs are variant copies; each has a GUIDE.md where present.

## Map of topics
- Probabilistic: Bloom filter
- Range queries: Fenwick tree, segment tree
- Linked structures: skip list
- Trees: red-black, treap, trie, merkle
- Connectivity: union-find
- Strings: suffix array

## Learning path
1. Fenwick and segment tree first (they cover most range queries).
2. Skip list as a randomized alternative.
3. Union-find for connectivity.
4. Bloom filters for streaming membership.
5. Suffix arrays and Merkle trees for strings/integrity.
