# EXERCISES — Data Structures Advanced

1. Implement a Fenwick and compute prefix sum/range sum for a sample array.
2. Add range-add via two Fenwicks (difference trick).
3. Implement a segment tree for range sum; query vs naive baseline.
4. Add lazy propagation for range add / range sum.
5. Build a skip list with geometric level promotion; verify O(log n) height.
6. Union-find with/without path compression: count steps on a chain.
7. Implement a Bloom filter; sweep k and measure false-positive rate.
8. Compute optimal k for m=1024 bits, n=100 items.
9. Build a Merkle tree over 8 leaves; produce and verify one proof.
10. Construct a suffix array of "banana"; list suffixes.
11. Add LCP array via Kasai's algorithm (O(n)).
12. Implement a treap; split/merge at k.
13. Implement trie with prefix counting.
14. Benchmark Fenwick vs segment tree for prefix-sum workloads.
15. Pick the right structure for 5 workloads (write the decision).
