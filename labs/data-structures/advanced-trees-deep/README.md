# advanced-trees-deep — Overview

Self-balancing and specialized trees in Java, from red-black trees to tries.

## Labs
- 01-redblacktree-deep — Red-Black Tree invariants and rotations
- 02-avltree-deep — AVL trees with strict height balance
- 03-splaytree-deep — Splay trees and amortized analysis
- 04-treap-deep — Randomized treaps, split/merge
- 05-btree-deep — B-trees and B+ trees
- 06-redblacktreemap-deep — JDK TreeMap internals
- 07-trie-deep — Tries and prefix search

## Learning path
1. Balance invariants first (AVL vs RB).
2. Rotations as local repairs.
3. Split/merge abstraction (treap).
4. Cache-aware nodes (B-tree).
5. Systems view (TreeMap, trie).
