# Sorting & Searching Deep Track — Overview

This track combines sorting and searching in depth: comparison sorts,
divide-and-conquer sorts, heap sort, linear sorts, binary search variants,
order statistics, string searching, and bit-level sort/search.

## Learning Objectives

- Compare quick/mergesort/heap trade-offs (stability, locality, guarantees)
- Apply linear sorts (counting/radix) under key constraints
- Search with bounds, rotation, peaks, and answer-search predicates
- Select order statistics + multi-pattern string search at scale

## Track contents

| # | Lab | Focus |
|---|---|---|
| 01 | comparison-sorts | insertion/merge/heap baselines |
| 02 | divide-conquer-sorts | quicksort variants, introsort |
| 03 | heap-sort | heapify, k-way merge |
| 04 | linear-sorts | counting, radix, bucket |
| 05 | binary-search-variants | bounds, rotated, peak |
| 06 | order-statistics | quickselect, MoM, heaps |
| 07 | string-searching | KMP, Rabin-Karp, Aho |
| 08 | bit-sort-search | bitwise tricks, binary trie |

## Prerequisites

- Arrays, recursion, heaps
- Big-O + recurrence basics

## Estimated Time

- **Theory**: 8 × 75 minutes
- **Practice**: 8 × 90 minutes
- **Total**: 3-4 weeks at 1 lab / 2 days
