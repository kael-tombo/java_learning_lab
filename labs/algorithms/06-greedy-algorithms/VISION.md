# VISION — Greedy Algorithms: Problem-Solving Mastery Path
> Where this lab takes you: from sorting tricks to proof-backed greed.

## The Arc
1. **Foundations** — greedy choice + exchange/stay-ahead proofs.
2. **Fluency** — activity/Huffman/Kruskal blind with invariants.
3. **Discrimination** — greedy vs DP (is choice safe? counterexample?).
4. **Scale** — matroids, approximation bounds (set cover, scheduling).
5. **Production** — compression, scheduling, network heuristics with fallback.

## Milestones
- [ ] M1: exchange proof sketched for one problem.
- [ ] M2: 0/1-knapsack greedy-breaker instance produced.
- [ ] M3: Huffman/Kruskal measured on skewed inputs.
- [ ] M4: approximation bound quoted for a heuristic.
- [ ] M5: design note proves or rejects greedy with evidence.

## Anti-Goals
- Greedy without proof or breaker-search; DP where greedy proven.

## Interview Lens
- "Prove it or break it?" — the greedy interview ritual.
