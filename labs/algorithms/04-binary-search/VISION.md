# VISION — Binary Search: Problem-Solving Mastery Path
> Where this lab takes you: from halving to boundary-hunting fluency.

## The Arc
1. **Foundations** — `[lo,hi)` invariant, overflow-safe mid, miss encoding.
2. **Fluency** — any-hit + lower/upper-bound blind; 2-element traces.
3. **Discrimination** — binary vs interpolation vs tree (distribution? inserts?).
4. **Scale** — search on answer (parametric), rotated arrays, 2-D matrices.
5. **Production** — range queries, version bisect, hot-path branch behavior.

## Milestones
- [ ] M1: invariant + shrink argument recited.
- [ ] M2: duplicate/empty/miss suites green.
- [ ] M3: lowerBound used in a real task (first-bad-version style).
- [ ] M4: rotated-array variant solved via invariant (not memorized).
- [ ] M5: bisect-driven bug hunt (regression range) documented.

## Anti-Goals
- Closed-interval off-by-ones; searching unsorted "almost sorted" data.

## Interview Lens
- "First occurrence?" (no early return). "Why `>>>1`?" (overflow).
