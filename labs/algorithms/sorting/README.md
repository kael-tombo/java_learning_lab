# Sorting Track — Overview

This track covers sorting via quicksort: Lomuto/Hoare partition,
3-way Dutch-flag, randomized pivot, and quickselect order statistics.

## Learning Objectives

- Prove partition invariants (no off-by-one)
- Implement 3-way partition for duplicate-heavy data
- Analyze average O(n log n) vs worst O(n²) + randomization fix
- Select kth via quickselect in expected O(n)

## Track contents

| Dir | Focus |
|---|---|
| quick-sort | partition schemes, 3-way, quickselect |

## Prerequisites

- Arrays, recursion, swaps
- Big-O + recurrence basics
