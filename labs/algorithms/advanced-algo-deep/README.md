# Advanced Algorithms Deep Track — Overview

This track groups 8 advanced labs: bit-manipulation-advanced,
number-theory-advanced, string-algorithms-advanced,
geometry-algorithms, combinatorial-algorithms, parallel-algorithms,
randomized-algorithms, and approximation-algorithms.

## Learning Objectives

- Master bit tricks, modular arithmetic, and automaton string search
- Solve geometry (convex hull, sweep line) and combinatorial search exactly
- Design parallel (work/span) and randomized (Las Vegas/Monte Carlo) algorithms
- Prove approximation ratios for NP-hard optimization

## Track contents

| # | Lab | Focus |
|---|---|---|
| 01 | bit-manipulation-advanced | masks, DP over subsets |
| 02 | number-theory-advanced | Miller-Rabin, Pollard Rho, CRT |
| 03 | string-algorithms-advanced | Aho-Corasick, suffix automaton |
| 04 | geometry-algorithms | hull, closest pair, sweep |
| 05 | combinatorial-algorithms | permutations, inclusion-exclusion |
| 06 | parallel-algorithms | work/span, prefix sums |
| 07 | randomized-algorithms | hashing, skip lists, Karger |
| 08 | approximation-algorithms | greedy ratios, LP rounding |

## Prerequisites

- Java arrays, sorting, recursion
- Big-O and recurrence basics

## Estimated Time

- **Theory**: 8 × 75 minutes
- **Practice**: 8 × 90 minutes
- **Total**: 3-4 weeks at 1 lab / 2 days
