# Data Structures Track — Overview

This track covers graph and tree structures: adjacency representations,
traversals (BFS/DFS), union-find, heaps, BSTs, segment trees, and tries.

## Learning Objectives

- Represent graphs (list vs matrix) and pick by density
- Traverse with BFS/DFS; detect cycles; topologically sort
- Operate union-find, heaps, BSTs, segment trees, tries
- Analyze amortized costs (union-find α, dynamic arrays)

## Track contents

| Dir | Focus |
|---|---|
| graphs | adjacency, BFS/DFS, cycle detection, union-find |
| trees | BST, heap, segment tree, trie, traversals |

## Prerequisites

- Java classes, generics, comparators
- Big-O basics

## Estimated Time

- **Theory**: 2 × 75 minutes
- **Practice**: 2 × 90 minutes
