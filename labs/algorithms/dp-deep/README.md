# DP Deep Track — Overview

This track covers dynamic programming in depth: classics, LCS/edit
distance, LIS/Kadane, knapsack variants, matrix-chain/string DP, tree DP,
digit DP, and DP optimizations (Knuth, Divide & Conquer, CHT).

## Learning Objectives

- State optimal substructure + overlapping subproblems per problem
- Choose memo vs tabulation; compress dimensions safely
- Apply knapsack/LCS/LIS patterns to unseen variants
- Use Knuth/D&C/CHT optimizations where quadrangle/monotonicity holds

## Track contents

| # | Lab | Focus |
|---|---|---|
| 01 | dp-classics | fib, coin change, climbing stairs |
| 02 | lcs-edit-distance | 2D string DP |
| 03 | lis-kadane | O(n log n) LIS, max subarray |
| 04 | knapsack-variants | 0/1, unbounded, bounded |
| 05 | matrix-chain-string-dp | intervals, gaps |
| 06 | tree-dp | rerooting, knapsack on tree |
| 07 | digit-dp | tight + pos + sum states |
| 08 | dp-optimizations | Knuth, D&C, Convex Hull Trick |

## Prerequisites

- Recursion + memoization basics
- 1D/2D arrays, Big-O

## Estimated Time

- **Theory**: 8 × 75 minutes
- **Practice**: 8 × 90 minutes
