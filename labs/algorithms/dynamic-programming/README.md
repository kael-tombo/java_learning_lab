# Dynamic Programming Track — Overview

This track introduces dynamic programming via memoization: recursion plus
cache over overlapping subproblems, then conversion to tabulation.

## Learning Objectives

- Spot optimal substructure + overlapping subproblems
- Write memoized recursion with correct state keys
- Convert memo to bottom-up tables; compress space
- Prove bounds by state-count × transition-cost

## Track contents

| Dir | Focus |
|---|---|
| memoization | fib, grid paths, coin change memoized |

## Prerequisites

- Recursion, arrays, HashMap
- Big-O basics
