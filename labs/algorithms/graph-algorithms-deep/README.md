# Graph Algorithms Deep Track — Overview

This track covers graphs in depth: spanning trees, all-pairs shortest
paths, max-flow/min-cut, bipartite matching, coloring, topo sort, cycle
detection, and heavy-light decomposition.

## Learning Objectives

- Build MSTs via cut/cycle properties (Kruskal/Prim/Boruvka)
- Run Dijkstra/Bellman-Ford/Floyd-Warshall with correct preconditions
- Solve max-flow (Dinic/push-relabel) and bipartite matching
- Color, topologically sort, detect cycles, decompose heavy-light paths

## Track contents

| # | Lab | Focus |
|---|---|---|
| 01 | spanning-trees | Kruskal/Prim/Boruvka |
| 02 | shortest-paths-all-pairs | Dijkstra/BF/Floyd |
| 03 | max-flow-min-cut | Dinic, push-relabel |
| 04 | bipartite-matching | Hopcroft-Karp, Hungarian |
| 05 | graph-coloring | DSATUR, bounds |
| 06 | topological-sort | Kahn, DFS finish |
| 07 | cycle-detection | colors, DSU, Bellman-Ford |
| 08 | heavy-light | HLD + segment tree |

## Prerequisites

- BFS/DFS + heaps + union-find
- Big-O and proof basics

## Estimated Time

- **Theory**: 8 × 75 minutes
