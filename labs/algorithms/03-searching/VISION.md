# VISION — Searching (Overview): Problem-Solving Mastery Path
> Where this lab takes you: from probes to retrieval architecture.

## The Arc
1. **Foundations** — linear/binary/hash contracts + sortedness precondition.
2. **Fluency** — all three implemented; miss encodings consistent.
3. **Discrimination** — decision matrix (order? queries? inserts? memory?).
4. **Scale** — indexes, Bloom prefilters, balanced trees for mutation-heavy.
5. **Production** — service search paths, version lookup, cache-assisted retrieval.
