# VISION — Graph Algorithms (Overview): Problem-Solving Mastery Path
> Where this lab takes you: from traversals to graph-system thinking.

## The Arc
1. **Foundations** — BFS/DFS/Dijkstra contracts + `O(V+E)` counting.
2. **Fluency** — forest loops, colors, PQ discipline across all three.
3. **Discrimination** — decision tree (unweighted? negative? all-pairs? DAG?).
4. **Scale** — SCC, MST, topo, max-flow as next layer.
5. **Production** — reachability, routing, dependency, fraud-ring patterns.
