# VISION — Recursion: Problem-Solving Mastery Path
> Where this lab takes you: from base cases to recurrence-driven design.

## The Arc
1. **Foundations** — base + progress + stack model; `T(n-1)` unrolling.
2. **Fluency** — countdown/tree recursions blind; depth estimated before coding.
3. **Discrimination** — recursion vs loop vs memo (overlap? depth? clarity?).
4. **Scale** — D&C, backtracking, DP-on-DAG built on recursion fluency.
5. **Production** — filesystem/AST walks with depth guards + iterative fallback.
