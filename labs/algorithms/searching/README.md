# Searching Track — Overview

This track covers searching: linear scan, binary search variants
(lower/upper bound, rotated, peak), interpolation, and exponential search.

## Learning Objectives

- Prove loop invariants for binary search (no off-by-one)
- Implement lower/upper bound, rotated-array, and peak search
- Choose linear vs binary vs interpolation by distribution
- Analyze via halving recurrences + amortized batch costs

- Arrays, loops, comparators
- Big-O basics
