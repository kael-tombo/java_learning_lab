1. **Foundations** — best/avg/worst, Ω/Θ/O, recurrence basics.
2. **Fluency** — Master + unrolling blind; doubling-ratio reading.
3. **Discrimination** — asymptotic vs constants vs memory hierarchy.
4. **Scale** — amortized + probabilistic + hardness (NP) awareness.
5. **Production** — SLO budgets, load projections, algo-choice notes.
