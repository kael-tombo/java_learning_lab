# Sql Basics

> Hands-on database lab: sql basics for Java developers.

## Objectives
- Understand the core concepts behind sql basics.
- Practice with real SQL, schemas, and tooling.
- Connect theory to production behavior and trade-offs.

## Contents
- THEORY.md — conceptual foundation
- EXERCISES.md — practice problems
- QUIZ.md — self-check
- FLASHCARDS.md — rapid recall
- MATH_FOUNDATION.md — quantitative grounding
- CODE_DEEP_DIVE.md — internals
- VISION.md — outcomes and milestones
- MINI_PROJECT.md — small build
- REAL_WORLD_PROJECT.md — capstone

## How to use this lab
1. Read THEORY.md first.
2. Work through EXERCISES.md without looking at hints.
3. Check yourself with QUIZ.md and FLASHCARDS.md.
4. Build MINI_PROJECT.md, then REAL_WORLD_PROJECT.md.

## Prerequisites
- Java 17+, Maven, Docker (for local databases).
- Basic SQL familiarity.

## Expected time
- About 4–8 hours across two sessions.
