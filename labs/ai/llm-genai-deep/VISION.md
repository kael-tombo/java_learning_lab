# VISION — LLM & GenAI Deep: Problem-Solving Mastery Path
> Where this lab takes you: from pretraining to production LLM systems.

## The Arc
1. **Foundations** — transformer architecture, tokenization, and pretraining objectives.
2. **Fluency** — implement attention, fine-tuning, and generation strategies.
3. **Discrimination** — choose between different LLM sizes and architectures.
4. **Scale** — distributed training, efficient inference, and scaling laws.
5. **Production** — RAG, fine-tuning, evaluation, and cost optimization.

## Milestones (checkable)
- [ ] M1: implement multi-head attention from scratch.
- [ ] M2: fine-tune a pretrained LLM on a custom task.
- [ ] M3: implement a RAG pipeline with vector search.
- [ ] M4: evaluate LLM outputs with automated metrics.
- [ ] M5: explain the trade-offs between fine-tuning and RAG.
