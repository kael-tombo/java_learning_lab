# VISION — Federated Learning: Problem-Solving Mastery Path
> Where this lab takes you: from distributed training to privacy-preserving ML.

## The Arc
1. **Foundations** — data decentralization, privacy constraints, and communication efficiency.
2. **Fluency** — implement FedAvg and FedProx.
3. **Discrimination** — choose between horizontal, vertical, and federated transfer learning.
4. **Scale** — differential privacy, secure aggregation, and Byzantine robustness.
5. **Production** — client selection, non-IID data handling, and system design.

## Milestones (checkable)
- [ ] M1: implement FedAvg for a simple classification task.
- [ ] M2: handle non-IID data distribution across clients.
- [ ] M3: add differential privacy to federated training.
- [ ] M4: implement secure aggregation protocol.
- [ ] M5: explain the trade-offs between privacy and utility.
