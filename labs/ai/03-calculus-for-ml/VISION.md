# VISION — Calculus for ML: Problem-Solving Mastery Path
> Where this lab takes you: from derivatives to gradient-based optimization.

## The Arc
1. **Foundations** — limits, derivatives, partial derivatives, chain rule.
2. **Fluency** — compute gradients of common functions; understand Jacobians.
3. **Discrimination** — know when to use gradient descent vs Newton's method.
4. **Scale** — multivariate calculus for neural network backpropagation.
5. **Production** — automatic differentiation and computational graphs.

## Milestones (checkable)
- [ ] M1: compute partial derivatives of f(x,y) = x^2*y + sin(y).
- [ ] M2: derive the gradient of the logistic loss function.
- [ ] M3: implement gradient descent for a simple quadratic function.
- [ ] M4: trace backpropagation through a 2-layer network by hand.
- [ ] M5: explain the vanishing gradient problem with calculus.

## Anti-Goals
- Memorizing derivative rules without understanding the chain rule deeply.
