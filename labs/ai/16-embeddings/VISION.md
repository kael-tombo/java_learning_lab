# VISION — Embeddings: Problem-Solving Mastery Path
> Where this lab takes you: from word vectors to dense representations.

## The Arc
1. **Foundations** — vector space models, similarity, and semantic relationships.
2. **Fluency** — implement word2vec (CBOW and skip-gram) and GloVe.
3. **Discrimination** — choose between static and contextual embeddings.
4. **Scale** — sentence embeddings, document embeddings, and retrieval.
5. **Production** — embedding storage, approximate nearest neighbors, and fine-tuning.

## Milestones (checkable)
- [ ] M1: compute cosine similarity between word vectors.
- [ ] M2: implement skip-gram with negative sampling.
- [ ] M3: visualize word embeddings using t-SNE.
- [ ] M4: use sentence transformers for semantic search.
- [ ] M5: explain the difference between word2vec and contextual embeddings.
