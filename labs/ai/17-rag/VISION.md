# VISION — RAG: Problem-Solving Mastery Path
> Where this lab takes you: from retrieval to generation in LLM systems.

## The Arc
1. **Foundations** — dense retrieval, sparse retrieval, and hybrid search.
2. **Fluency** — implement a basic RAG pipeline with vector store and LLM.
3. **Discrimination** — choose between different chunking and retrieval strategies.
4. **Scale** — advanced RAG: re-ranking, query expansion, and multi-hop retrieval.
5. **Production** — evaluation, hallucination reduction, and cost optimization.

## Milestones (checkable)
- [ ] M1: build a simple RAG system with a vector database.
- [ ] M2: implement chunking strategies and evaluate retrieval quality.
- [ ] M3: add re-ranking to improve retrieval precision.
- [ ] M4: evaluate RAG output with faithfulness and relevance metrics.
- [ ] M5: explain the trade-offs between RAG and fine-tuning.

## Anti-Goals
- Using RAG without evaluating retrieval quality separately from generation.
