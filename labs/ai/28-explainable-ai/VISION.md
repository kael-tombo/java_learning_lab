# VISION — Explainable AI: Problem-Solving Mastery Path
> Where this lab takes you: from feature attribution to interpretable models.

## The Arc
1. **Foundations** — interpretability vs explainability, stakeholder needs, and regulatory context.
2. **Fluency** — implement LIME, SHAP, and integrated gradients.
3. **Discrimination** — choose between model-agnostic and model-specific explanation methods.
4. **Scale** — attention visualization, concept-based explanations, and counterfactuals.
5. **Production** — explanation quality evaluation, user studies, and documentation.

## Milestones (checkable)
- [ ] M1: implement LIME for local explanations.
- [ ] M2: compute SHAP values for a tree-based model.
- [ ] M3: implement integrated gradients for a neural network.
- [ ] M4: generate counterfactual explanations.
- [ ] M5: explain the difference between global and local explanations.

## Anti-Goals
- Providing explanations without validating their faithfulness.
