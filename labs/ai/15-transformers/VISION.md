# VISION — Transformers: Problem-Solving Mastery Path
> Where this lab takes you: from self-attention to large language models.

## The Arc
1. **Foundations** — attention mechanism, multi-head attention, and positional encoding.
2. **Fluency** — implement self-attention and transformer blocks from scratch.
3. **Discrimination** — understand encoder-only, decoder-only, and encoder-decoder variants.
4. **Scale** — BERT, GPT, T5, and scaling laws.
5. **Production** — fine-tuning, prompt engineering, and efficient inference.

## Milestones (checkable)
- [ ] M1: compute scaled dot-product attention by hand.
- [ ] M2: implement a single transformer encoder layer.
- [ ] M3: train a small transformer on a text classification task.
- [ ] M4: fine-tune a pretrained BERT model.
- [ ] M5: explain the difference between BERT and GPT architectures.

## Anti-Goals
