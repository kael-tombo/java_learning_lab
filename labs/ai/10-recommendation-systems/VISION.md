# VISION — Recommendation Systems: Problem-Solving Mastery Path
> Where this lab takes you: from collaborative filtering to modern hybrid systems.

## The Arc
1. **Foundations** — user-item matrices, sparsity, and the cold start problem.
2. **Fluency** — implement user-based and item-based collaborative filtering.
3. **Discrimination** — choose between content-based, collaborative, and hybrid approaches.
4. **Scale** — matrix factorization, SVD++, and deep learning recommenders.
5. **Production** — A/B testing, diversity, and real-time recommendation serving.

## Milestones (checkable)
- [ ] M1: compute user-user similarity using cosine similarity.
- [ ] M2: implement item-based collaborative filtering.
- [ ] M3: perform matrix factorization using SGD.
- [ ] M4: evaluate with precision@k, recall@k, and NDCG.
- [ ] M5: explain the cold start problem and mitigation strategies.
