# VISION — Probability for ML: Problem-Solving Mastery Path
> Where this lab takes you: from Bayes' theorem to probabilistic ML pipelines.

## The Arc
1. **Foundations** — sample spaces, events, axioms, conditional probability.
2. **Fluency** — apply Bayes' theorem; compute expectations and variances.
3. **Discrimination** — choose the right distribution for a given problem.
4. **Scale** — MLE, Bayesian inference, and entropy in ML contexts.
5. **Production** — uncertainty quantification and calibration in real systems.

## Milestones (checkable)
- [ ] M1: derive Bayes' theorem from conditional probability definition.
- [ ] M2: compute posterior probabilities for a medical test scenario.
- [ ] M3: implement MLE for Gaussian distribution from scratch.
- [ ] M4: calculate entropy and KL divergence for given distributions.
- [ ] M5: explain the difference between MLE and MAP estimation.
