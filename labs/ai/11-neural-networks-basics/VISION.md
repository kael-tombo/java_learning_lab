# VISION — Neural Networks Basics: Problem-Solving Mastery Path
> Where this lab takes you: from perceptrons to multi-layer networks.

## The Arc
1. **Foundations** — neurons, activation functions, and network architectures.
2. **Fluency** — implement forward pass and backpropagation by hand.
3. **Discrimination** — choose between different activation functions and architectures.
4. **Scale** — initialization strategies, batch normalization, and dropout.
5. **Production** — debugging training, learning rate tuning, and overfitting prevention.

## Milestones (checkable)
- [ ] M1: compute the forward pass for a 2-layer network by hand.
- [ ] M2: implement backpropagation for a single hidden layer network.
- [ ] M3: compare ReLU, sigmoid, and tanh activation functions.
- [ ] M4: implement Xavier/He initialization.
- [ ] M5: explain the vanishing gradient problem and solutions.

## Anti-Goals
- Using deep networks when shallow ones suffice.

## Interview Lens
