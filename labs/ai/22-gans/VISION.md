# VISION — GANs: Problem-Solving Mastery Path
> Where this lab takes you: from adversarial training to modern generative models.

## The Arc
1. **Foundations** — generator, discriminator, minimax game, and Nash equilibrium.
2. **Fluency** — implement a basic GAN and DCGAN.
3. **Discrimination** — choose between different GAN variants (WGAN, CycleGAN, StyleGAN).
4. **Scale** — conditional GANs, progressive growing, and diffusion models.
5. **Production** — mode collapse detection, evaluation metrics, and ethical considerations.

## Milestones (checkable)
- [ ] M1: implement a basic GAN for generating simple distributions.
- [ ] M2: train a DCGAN on MNIST.
- [ ] M3: implement WGAN with gradient penalty.
- [ ] M4: evaluate GAN quality with FID and IS metrics.
- [ ] M5: explain mode collapse and mitigation strategies.

## Anti-Goals
- Training GANs without monitoring for mode collapse.
