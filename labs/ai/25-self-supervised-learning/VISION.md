# VISION — Self-Supervised Learning: Problem-Solving Mastery Path
> Where this lab takes you: from pretext tasks to contrastive learning.

## The Arc
1. **Foundations** — pretext tasks, representation learning, and downstream transfer.
2. **Fluency** — implement autoencoding, contrastive, and masked prediction objectives.
3. **Discrimination** — choose between different SSL strategies for different modalities.
4. **Scale** — SimCLR, MoCo, BYOL, and masked autoencoders.
5. **Production** — pretraining pipelines, evaluation protocols, and fine-tuning.

## Milestones (checkable)
- [ ] M1: implement a simple contrastive learning objective.
- [ ] M2: train a SimCLR model on unlabeled images.
- [ ] M3: implement masked language modeling.
- [ ] M4: evaluate learned representations on downstream tasks.
- [ ] M5: explain the difference between contrastive and non-contrastive SSL.

## Anti-Goals
