# VISION — Neural Networks Deep: Problem-Solving Mastery Path
> Where this lab takes you: from perceptrons to modern architectures.

## The Arc
1. **Foundations** — neuron models, activation functions, and network topologies.
2. **Fluency** — implement forward and backward passes for various architectures.
3. **Discrimination** — choose between architectures based on problem characteristics.
4. **Scale** — normalization, regularization, and optimization techniques.
5. **Production** — debugging, profiling, and deploying neural networks.

## Milestones (checkable)
- [ ] M1: implement a perceptron and train it on a simple dataset.
- [ ] M2: implement a multi-layer perceptron with backpropagation.
- [ ] M3: implement batch normalization and dropout.
- [ ] M4: implement a residual network.
- [ ] M5: explain the vanishing gradient problem and solutions.
