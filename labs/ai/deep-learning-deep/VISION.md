# VISION — Deep Learning Deep: Problem-Solving Mastery Path
> Where this lab takes you: from backpropagation to modern deep architectures.

## The Arc
1. **Foundations** — neural network fundamentals, activation functions, and optimization.
2. **Fluency** — implement CNNs, RNNs, and transformers from scratch.
3. **Discrimination** — choose between architectures based on data and task.
4. **Scale** — distributed training, mixed precision, and model parallelism.
5. **Production** — model compression, quantization, and serving infrastructure.

## Milestones (checkable)

- [ ] M4: train a model with mixed precision.
- [ ] M5: explain the trade-offs between different architectures.
