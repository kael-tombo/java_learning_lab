# VISION — Optimization: Problem-Solving Mastery Path
> Where this lab takes you: from gradient descent to convex optimization theory.

## The Arc
1. **Foundations** — objective functions, convexity, gradients, Hessians.
2. **Fluency** — implement gradient descent, SGD, and momentum.
3. **Discrimination** — choose between first-order and second-order methods.
4. **Scale** — constrained optimization, Lagrange multipliers, duality.
5. **Production** — learning rate schedules, adaptive optimizers (Adam, RMSprop).

## Milestones (checkable)
- [ ] M1: prove a function is convex using the definition.
- [ ] M2: implement gradient descent with fixed learning rate.
- [ ] M3: compare convergence of GD vs SGD on a quadratic bowl.
- [ ] M4: derive the update rule for momentum-based gradient descent.
- [ ] M5: explain why Adam works well in practice.

## Anti-Goals
- Blindly using Adam without understanding its components.
