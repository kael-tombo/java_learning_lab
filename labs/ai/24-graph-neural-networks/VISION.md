# VISION — Graph Neural Networks: Problem-Solving Mastery Path
> Where this lab takes you: from message passing to graph transformers.

## The Arc
1. **Foundations** — graph representation, adjacency matrices, and node features.
2. **Fluency** — implement GCN, GAT, and GraphSAGE.
3. **Discrimination** — choose between different GNN architectures for different tasks.
4. **Scale** — graph transformers, heterogeneous graphs, and large-scale GNNs.
5. **Production** — graph construction, evaluation, and deployment.

## Milestones (checkable)
- [ ] M1: implement a simple GCN for node classification.
- [ ] M2: implement GAT with attention mechanism.
- [ ] M3: perform graph-level classification with graph pooling.
- [ ] M4: handle heterogeneous graphs with R-GCN.
- [ ] M5: explain the over-smoothing problem in GNNs.
