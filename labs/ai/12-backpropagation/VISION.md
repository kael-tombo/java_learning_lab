# VISION — Backpropagation: Problem-Solving Mastery Path
> Where this lab takes you: from chain rule to automatic differentiation.

## The Arc
1. **Foundations** — chain rule, computational graphs, and gradient flow.
2. **Fluency** — derive gradients for common layers (linear, conv, recurrent).
3. **Discrimination** — understand when gradients vanish, explode, or saturate.
4. **Scale** — implement backprop through complex architectures (ResNet, LSTM).
5. **Production** — gradient checking, mixed precision, and memory-efficient training.

## Milestones (checkable)
- [ ] M1: derive the gradient of a simple computational graph by hand.
- [ ] M2: implement backpropagation for a fully connected network.
- [ ] M3: perform gradient checking to verify implementation.
- [ ] M4: implement backprop through a convolutional layer.
- [ ] M5: explain how residual connections help gradient flow.

## Anti-Goals
- Implementing backprop without understanding the chain rule.
