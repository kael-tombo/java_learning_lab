# VISION — Linear Algebra for ML: Problem-Solving Mastery Path
> Where this lab takes you: from vector intuition to matrix decompositions powering ML.

## The Arc
1. **Foundations** — vectors, matrices, operations, and geometric intuition.
2. **Fluency** — implement matrix multiply, transpose, inverse blind; edge cases green.
3. **Discrimination** — know when to use LU vs QR vs Cholesky vs SVD.
4. **Scale** — eigenvalues, eigenvectors, and spectral theorem for PCA.
5. **Production** — numerical stability, conditioning, and library awareness.

## Milestones (checkable)
- [ ] M1: compute dot product, norm, and angle between vectors without code.
- [ ] M2: implement matrix multiplication and verify with hand calculation.
- [ ] M3: SVD decomposition of a 3x3 matrix; interpret singular values.
- [ ] M4: use eigenvalues to determine matrix definiteness.
- [ ] M5: explain why SVD is preferred over eigendecomposition for non-square matrices.

## Anti-Goals
- Memorizing formulas without geometric intuition; ignoring numerical precision.

## Interview Lens
- "Why is SVD more general than eigendecomposition?" "What does a small singular value mean?"
