# VISION — Reinforcement Learning: Problem-Solving Mastery Path
> Where this lab takes you: from MDPs to deep Q-networks and policy gradients.

## The Arc
1. **Foundations** — MDPs, rewards, policies, and value functions.
2. **Fluency** — implement Q-learning, SARSA, and policy gradient methods.
3. **Discrimination** — choose between value-based, policy-based, and actor-critic methods.
4. **Scale** — deep Q-networks, PPO, and multi-agent RL.
5. **Production** — simulation environments, reward shaping, and safe exploration.

## Milestones (checkable)
- [ ] M1: solve a small MDP using value iteration.
- [ ] M2: implement Q-learning for a grid world.
- [ ] M3: implement REINFORCE policy gradient algorithm.
- [ ] M4: train a DQN on a simple environment.
- [ ] M5: explain the exploration-exploitation tradeoff.

## Anti-Goals
- Applying RL without understanding the underlying MDP structure.
