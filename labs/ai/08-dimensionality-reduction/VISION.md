# VISION — Dimensionality Reduction: Problem-Solving Mastery Path
> Where this lab takes you: from PCA to manifold learning techniques.

## The Arc
1. **Foundations** — curse of dimensionality, variance preservation, linear projections.
2. **Fluency** — implement PCA, LDA, and t-SNE.
3. **Discrimination** — know when to use linear vs nonlinear dimensionality reduction.
4. **Scale** — autoencoders, UMAP, and feature selection methods.
5. **Production** — choosing components, interpreting embeddings, and visualization.

## Milestones (checkable)
- [ ] M1: compute PCA on a dataset and plot explained variance.
- [ ] M2: implement PCA using SVD and verify with covariance matrix method.
- [ ] M3: compare PCA and t-SNE on the same dataset.
- [ ] M4: use LDA for supervised dimensionality reduction.
- [ ] M5: explain the difference between PCA and autoencoders.

## Anti-Goals
- Applying dimensionality reduction without understanding information loss.
