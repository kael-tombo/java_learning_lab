# VISION — Classical ML Deep: Problem-Solving Mastery Path
> Where this lab takes you: from classical algorithms to production ML systems.

## The Arc
1. **Foundations** — supervised vs unsupervised learning, bias-variance tradeoff.
2. **Fluency** — implement decision trees, random forests, and gradient boosting.
3. **Discrimination** — choose between linear models, trees, and kernel methods.
4. **Scale** — ensemble methods, stacking, and hyperparameter optimization.
5. **Production** — feature engineering, model selection, and deployment pipelines.

## Milestones (checkable)
- [ ] M1: implement a decision tree from scratch.

- [ ] M3: implement gradient boosting and tune hyperparameters.
- [ ] M4: perform feature selection and engineering.
- [ ] M5: explain the bias-variance tradeoff in practice.
