# VISION — Anomaly Detection: Problem-Solving Mastery Path
> Where this lab takes you: from statistical methods to deep learning approaches.

## The Arc
1. **Foundations** — types of anomalies, contamination, and evaluation challenges.
2. **Fluency** — implement z-score, IQR, and isolation forest.
3. **Discrimination** — choose between statistical, distance-based, and density-based methods.
4. **Scale** — autoencoders, one-class SVM, and LOF.
5. **Production** — threshold selection, false positive management, and real-time detection.

## Milestones (checkable)
- [ ] M1: detect anomalies using z-score and IQR methods.
- [ ] M2: implement isolation forest and compare with LOF.
- [ ] M3: train an autoencoder for anomaly detection.
- [ ] M4: evaluate anomaly detection with precision-recall curves.
- [ ] M5: explain why accuracy is a poor metric for anomaly detection.

## Anti-Goals
