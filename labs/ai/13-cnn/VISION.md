# VISION — CNN: Problem-Solving Mastery Path
> Where this lab takes you: from convolutional filters to modern architectures.

## The Arc
1. **Foundations** — convolution operation, pooling, and feature maps.
2. **Fluency** — implement convolution, pooling, and backprop through conv layers.
3. **Discrimination** — choose between different architectures (LeNet, AlexNet, ResNet).
4. **Scale** — transfer learning, data augmentation, and object detection.
5. **Production** — model compression, quantization, and deployment on edge devices.

## Milestones (checkable)
- [ ] M1: compute the output of a convolutional layer by hand.
- [ ] M2: implement a simple CNN for MNIST classification.
- [ ] M3: apply transfer learning with a pretrained ResNet.
- [ ] M4: visualize feature maps and filters.
- [ ] M5: explain the role of 1x1 convolutions.

## Anti-Goals
- Using CNNs for non-spatial data without justification.
