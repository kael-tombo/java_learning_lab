# VISION — Multi-Task Learning: Problem-Solving Mastery Path
> Where this lab takes you: from shared representations to task relationships.

## The Arc
1. **Foundations** — task relatedness, shared vs task-specific parameters, and loss balancing.
2. **Fluency** — implement hard and soft parameter sharing architectures.
3. **Discrimination** — choose between MTL strategies based on task relationships.
4. **Scale** — gradient surgery, uncertainty weighting, and task routing.
5. **Production** — task weighting, evaluation, and negative transfer mitigation.

## Milestones (checkable)
- [ ] M1: implement a shared-bottom MTL model.
- [ ] M2: implement cross-stitch networks for task combination.
- [ ] M3: apply gradient surgery (PCGrad) to conflicting gradients.
- [ ] M4: evaluate MTL vs single-task learning on multiple tasks.
- [ ] M5: explain negative transfer and how to detect it.
