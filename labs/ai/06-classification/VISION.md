# VISION — Classification: Problem-Solving Mastery Path
> Where this lab takes you: from decision boundaries to multi-class strategies.

## The Arc
1. **Foundations** — decision boundaries, loss functions, evaluation metrics.
2. **Fluency** — implement logistic regression, SVM, and k-NN.
3. **Discrimination** — choose between linear and kernel-based classifiers.
4. **Scale** — multi-class classification, imbalanced data, calibration.
5. **Production** — threshold tuning, ROC analysis, and model monitoring.

## Milestones (checkable)
- [ ] M1: derive the logistic regression decision boundary.
- [ ] M2: implement k-NN and compare with logistic regression.
- [ ] M3: compute precision, recall, F1, and AUC for a classifier.
- [ ] M4: handle class imbalance with SMOTE and class weights.
- [ ] M5: explain the kernel trick in SVM.

## Anti-Goals
- Using accuracy as the sole metric for imbalanced datasets.

## Interview Lens
- "When would you prefer SVM over logistic regression?" "How do you calibrate probabilities?"
