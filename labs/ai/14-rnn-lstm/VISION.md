# VISION — RNN/LSTM: Problem-Solving Mastery Path
> Where this lab takes you: from sequence modeling to attention mechanisms.

## The Arc
1. **Foundations** — recurrence, hidden states, and sequence-to-sequence models.
2. **Fluency** — implement forward and backward passes for RNN and LSTM.
3. **Discrimination** — choose between RNN, LSTM, and GRU for different tasks.
4. **Scale** — bidirectional RNNs, stacked RNNs, and encoder-decoder architectures.
5. **Production** — handling variable-length sequences, padding, and bucketing.

## Milestones (checkable)
- [ ] M1: compute the forward pass for a simple RNN by hand.
- [ ] M2: implement LSTM cell and compare with vanilla RNN.
- [ ] M3: train a character-level language model.
- [ ] M4: implement a sequence-to-sequence model with attention.
- [ ] M5: explain why LSTMs mitigate the vanishing gradient problem.

## Anti-Goals
