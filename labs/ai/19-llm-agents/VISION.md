# VISION — LLM Agents: Problem-Solving Mastery Path
> Where this lab takes you: from tool use to autonomous multi-agent systems.

## The Arc
1. **Foundations** — agent architecture, tool use, and planning.
2. **Fluency** — implement a simple agent with function calling and memory.
3. **Discrimination** — choose between single-agent and multi-agent architectures.
4. **Scale** — ReAct, plan-and-execute, and reflection patterns.
5. **Production** — safety guardrails, cost control, and observability.

## Milestones (checkable)
- [ ] M1: implement a basic agent with tool use.
- [ ] M2: add short-term and long-term memory to an agent.
- [ ] M3: implement the ReAct pattern (reasoning + acting).
- [ ] M4: build a multi-agent system for a complex task.
- [ ] M5: explain the challenges of agent reliability and safety.

## Anti-Goals
- Building agents without safety constraints and cost limits.

## Interview Lens
- "How do you handle agent hallucinations?" "What is the ReAct pattern?"
