# VISION — Meta-Learning: Problem-Solving Mastery Path
> Where this lab takes you: from learning to learn to few-shot adaptation.

## The Arc
1. **Foundations** — meta-learning problem formulation, task distributions, and adaptation.
2. **Fluency** — implement MAML, Prototypical Networks, and Reptile.
3. **Discrimination** — choose between optimization-based, metric-based, and model-based methods.
4. **Scale** — meta-learning for NLP, RL, and continual learning.
5. **Production** — task design, evaluation protocols, and computational efficiency.

## Milestones (checkable)
- [ ] M1: implement Prototypical Networks for few-shot classification.
- [ ] M2: implement MAML for few-shot regression.
- [ ] M3: compare MAML with first-order MAML (FOMAML).
- [ ] M4: evaluate on miniImageNet or Omniglot.
- [ ] M5: explain the difference between meta-learning and transfer learning.

## Anti-Goals
- Applying meta-learning without understanding the task distribution.
