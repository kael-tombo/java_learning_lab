# VISION — Prompt Engineering: Problem-Solving Mastery Path
> Where this lab takes you: from zero-shot to advanced prompting techniques.

## The Arc
1. **Foundations** — prompt structure, tokenization, and LLM behavior.
2. **Fluency** — implement few-shot, chain-of-thought, and self-consistency prompting.
3. **Discrimination** — choose between different prompting strategies for different tasks.
4. **Scale** — prompt chaining, tool use, and structured output generation.
5. **Production** — prompt versioning, A/B testing, and cost optimization.

## Milestones (checkable)
- [ ] M1: design prompts for classification, extraction, and generation tasks.
- [ ] M2: implement chain-of-thought prompting and measure improvement.
- [ ] M3: use few-shot learning with carefully selected examples.
- [ ] M4: implement structured output generation with JSON schema.
- [ ] M5: explain the difference between zero-shot, few-shot, and fine-tuning.
