# VISION — Regression: Problem-Solving Mastery Path
> Where this lab takes you: from OLS to regularized regression in production.

## The Arc
1. **Foundations** — linear regression, least squares, cost functions.
2. **Fluency** — implement OLS, ridge, and lasso from scratch.
3. **Discrimination** — know when to use linear vs polynomial vs regularized regression.
4. **Scale** — logistic regression, GLMs, and probabilistic interpretations.
5. **Production** — feature engineering, cross-validation, and model diagnostics.

## Milestones (checkable)
- [ ] M1: derive the normal equations for OLS regression.
- [ ] M2: implement gradient descent for linear regression.
- [ ] M3: compare ridge and lasso on a multicollinear dataset.
- [ ] M4: compute R², adjusted R², and RMSE for a fitted model.
- [ ] M5: explain the bias-variance tradeoff in regression.

## Anti-Goals
- Fitting models without checking residuals or assumptions.

## Interview Lens
- "Why does lasso produce sparse solutions?" "How do you handle outliers?"
