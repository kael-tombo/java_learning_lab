# VISION — Fine-Tuning: Problem-Solving Mastery Path
> Where this lab takes you: from full fine-tuning to parameter-efficient methods.

## The Arc
1. **Foundations** — transfer learning, catastrophic forgetting, and domain adaptation.
2. **Fluency** — implement full fine-tuning and LoRA on a pretrained model.
3. **Discrimination** — choose between full fine-tuning, LoRA, and prompt tuning.
4. **Scale** — instruction tuning, RLHF, and DPO.
5. **Production** — evaluation, deployment, and monitoring fine-tuned models.

## Milestones (checkable)
- [ ] M1: fine-tune a small transformer on a custom dataset.
- [ ] M2: implement LoRA and compare with full fine-tuning.
- [ ] M3: evaluate fine-tuned model with perplexity and task-specific metrics.
- [ ] M4: implement instruction tuning with a dataset.
- [ ] M5: explain the trade-offs between different fine-tuning methods.

## Anti-Goals
- Fine-tuning without a clear evaluation strategy.
