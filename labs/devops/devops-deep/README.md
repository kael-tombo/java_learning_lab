# DevOps Deep Dive

## Overview
A capstone track that weaves together advanced DevOps topics: GitOps,
service meshes, container security, secret management, feature flags,
canary deployments, SRE practices, and incident management.

## Sub-labs
- `01-gitops-deep` — reconciliation, Argo CD, app-of-apps
- `02-service-mesh-deep` — data plane vs control plane, mTLS, L7 policy
- `03-container-security-deep` — image signing, admission control
- `04-secret-management` — Vault, dynamic credentials, rotation
- `05-feature-flags` — decoupling deploy from release
- `06-canary-deployments` — progressive delivery
- `07-sre-practices` — SLOs, error budgets, burn rates
- `08-incident-management` — on-call, severity, postmortems

## Prerequisites
- Kubernetes, Docker, CI/CD, Terraform basics (labs 01–15)

## How to use
- Read `THEORY.md` for cross-cutting concepts.
- Do `EXERCISES.md` and check `QUIZ.md` / `FLASHCARDS.md`.
- Read `MATH_FOUNDATION.md` for the quantitative side (availability, burn).
- Build `MINI_PROJECT.md`, then plan `REAL_WORLD_PROJECT.md`.
